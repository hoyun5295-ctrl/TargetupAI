## §0 왜 결함이 남았나

- C110 흐름 표(`docs/2026-11-06-effect-proof-flow-ledger.md` · 1106 Harold 확인)는 발송 입구와 판정 순서를 뽑았지만, 판정 자리마다의 **「누가」 값 범위**(회사 요금제 · 사용자 역할)와 **「누가 보나」 화면 축**(설정 칸 · 결과 카드 단추)이 없었다.
- 입구 추출이 **파일 단위**였다(공용 발송 입구 `createDirectSendCampaign` 를 부르는 파일 + 옛 피로도 함수를 부르던 파일 · `c110-contract-1106.test.ts:33-46`). 같은 파일 안의 다른 라우트(브랜드 메시지)와 다른 채널 파일(이메일 · 푸시)은 추출에 들어오지 않았다.
- 1106 Harold 「미가입자는 관계가 없어야」를 원장 잇기 이음매 하나(`marked`)에만 넣고, 모든 판정 자리의 값 범위 줄로 넣지 않았다.
- Codex 설계 · 구현 리뷰는 설계서 범위 안만 판정했다. 범위 밖은 몇 라운드를 돌아도 보지 않는다(DEFECT-PLAYBOOK §0 과 같은 꼴).
