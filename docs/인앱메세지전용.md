## 0. 진정 핵심 원칙

### 0-1. 디자인 = AI 여정 자동화 (`/ai-journeys`) 동급 퀄리티 의무

옛 Journey Builder (`JourneysPage.tsx` 2507줄) 영역 안 모든 시각 패턴을 인앱메시지 영역 안 그대로 적용:

| Journey 영역 | 인앱메시지 영역 안 적용 매트릭스 |
|---|---|
| `view = 'main' \| 'review'` 2단계 흐름 | 신규 메시지 = '자연어 입력' → 'AI 생성 중' → '검토 + 편집' 3단계 흐름 |
| 자연어 입력 (fuchsia/purple/indigo 그라데이션 + Sparkles) | 인앱메시지 자연어 입력 카드 동일 디자인 |
| 빠른 시작 카드 7 템플릿 (TEMPLATE_VISUAL — icon + gradient + label + hint) | 인앱 빠른 시작 카드 7 시나리오 (장바구니 회복 / 신규 환영 / 휴면 회수 / 신상품 / VIP 감사 / 결제 직전 이탈 방지 / 재구매 유도) — 각각 고유 icon + gradient |
| 6 sub-agent 진행 카드 (JOURNEY_SUB_AGENT_STEPS — 5초 시각 효과) | 인앱 6 sub-agent (Trigger Detection / Audience Match / Template Selection / Copy Design / Variant Generation / Review Ready) |
| 흐름 다이어그램 (JourneyFlowDiagram) | 인앱 표시 흐름 다이어그램 (트리거 → 세그먼트 매칭 → 표시 → 클릭/dismiss → 전환) |
| 시뮬레이션 카드 (활성화 직전 — 매칭 customer / 예상 impression / 예상 CTR) | 인앱 시뮬레이션 카드 (활성화 직전 — 매칭 customer / 예상 24h impression / 예상 CTR / 예상 매출 영향) |
| Funnel 시각화 (각 step 색상 막대 + 이탈 사유 5 매트릭스) | 인앱 Funnel (impression → click → 24h purchase + dismiss 이유 분석) |
| 보관함 영역 (archive/unarchive/영구 삭제 — 다크 톤 ConfirmModal) | 인앱 보관함 동일 — JourneyActionConfirmModal 패턴 재사용 |
| 상태 필터 토글 (전체/활성/일시정지/종료/보관함) | 인앱 상태 필터 동일 (+ template별 필터 추가) |
| Variant 편집 (JourneyVariantsEditor — A/B 본문 영역) | 인앱 Variant 편집 (A/B/C 본문 + 색상 + 이미지 변형) |
| 단계별 AI 진단 (severity good/warning/critical + 1-click 추천) | 인앱 메시지 AI 진단 (CTR 영향 요인 + 1-click 다듬기) |
| next step 추천 (AI가 다음 단계 자동 제안) | 인앱 next message 추천 (현재 메시지 활성 후 → 다음 메시지 자동 제안) |
| 실시간 진행 위치 카드 (active 여정 — 현재 N명) | 인앱 실시간 카드 (지난 24h impression / 활성 사용자 / 현재 표시 중 N개) |
| 다중 미리보기 (sample customer 3건 — 등급별) | 인앱 다중 미리보기 (mobile + PC + sample customer 3건 등급별 — Liquid 변수 치환 렌더링) |
| LiquidPreviewModal (변수 치환 미리보기) | 인앱 동일 — 인앱 안 변수 치환 렌더링 미리보기 |

## 2. 압도적 강화 설계안 (D215+ 단일 정답)

### 핵심 강화 5축

#### 축 1. AI 자동 생성 (Opus 4.7 — UI 노출 절대 금지)
Journey Builder 동일 패턴 — **자연어 한 줄 → 5초 안 완성**:
- 입력 (예: "장바구니 24시간 후 회복 메시지" / "신규 가입자 환영 인사")
- AI 도출: 제목 + 본문 + CTA + 트리거 + 빈도 + 세그먼트 + 시간대 + 위치 + 색상 + 이미지 추천
- 빠른 시작 카드 **7 시나리오** (Journey 7 템플릿 정합):
  1. 장바구니 회복 (cart 아이콘 + amber→orange 그라데이션)
  2. 신규 가입 환영 (UserPlus 아이콘 + emerald→teal)
  3. 휴면 회수 (Moon 아이콘 + violet→indigo)
  4. 신상품 출시 안내 (Sparkles 아이콘 + fuchsia→purple)
  5. VIP 감사 (Crown 아이콘 + amber→yellow)
  6. 결제 직전 이탈 방지 (AlertTriangle 아이콘 + rose→pink)
  7. 재구매 유도 (Repeat 아이콘 + cyan→blue)
- 영구 룰: AI는 구체 혜택(%/원/쿠폰/무료) 절대 미생성 — `[직접 작성해주세요]` placeholder

#### 축 2. 세그먼트 + 개인화 (Personalization Engine)
D214+ Unified Customer Profile 통합:
- customer 조건 (등급/지역/연령/LTV/cart_add_count_30d/last_activity_at/primary_source)
- cdp_events 조건 (지난 N일 cart_add/purchase/page_view 매칭)
- Liquid templating — `{{customer.name}}` / `{{customer.points}}` / `{{recent_product}}` / `{{cart_count}}` / `{{last_purchase_days_ago}}`
- 비회원 (anonymous_id) = 기본 인사 fallback

#### 축 3. 컴포넌트 8 templates + 디자인 강화

| Template | 용도 | 핵심 |
|---|---|---|
| **top_banner** | 옛 영역 — 공지/홍보 | 화면 상단 고정 |
| **bottom_banner** | 옛 영역 — 동의/안내 | 화면 하단 고정 |
| **center_modal** | 옛 영역 — 중요 알림 | 중앙 backdrop 모달 |
| **full_screen** (신규) | 신규 가입 환영 / 온보딩 | 전체 화면 — 5단계 슬라이드 가능 |
| **slide_in** (신규) | 우측 슬라이드 알림 | 우측에서 슬라이드 + 자동 닫힘 |
| **inline_card** (신규) | 페이지 안 추천 카드 | DOM 안 inline 삽입 (selector 지정) |
| **toast** (신규) | 우상단 작은 confirmation | 3초 자동 닫힘 |
| **floating_button** (신규) | 플로팅 CTA | 우하단 고정 — 장바구니/문의 진입 |

추가 요소:
- 이미지 업로드 (S3 또는 자체 호스팅 영역)
- 다중 CTA (최대 3 버튼 — 각 button별 click 트래킹 분리)
- 애니메이션 (fade / slide / bounce / pulse)
- 자동 dismiss (N초 후 자동 닫힘)
- 모바일/PC 반응형 자동 정합

#### 축 4. A/B + Bandit 자동 최적화
D177 Bandit Optimizer (Thompson Sampling Beta-Bernoulli) 정합:
- AI가 variant 자동 생성 (Opus 4.7 — 카피 톤 3종: 감성/실용/캐주얼)
- impression/click 영역 reward 자동 학습
- 95% CI 도달 시 winner 자동 적용
- cold start = explore 가중치
- sticky bucketing (동일 사용자에게 동일 variant 영구 표시)

#### 축 5. AI 자율 진단 + 1-click 액션
Performance Explainer (CT-67) 정합:
- CTR 낮은 메시지 영향 요인 분석 (Opus 4.7) — 이미지 / CTA 색상 / 트리거 시점 / 본문 길이 / 세그먼트 정확도
- 1-click 액션 3 카드:
  - **AI 자동 다듬기** — variant 자동 생성 → A/B 자동 시작
  - **시간대 최적화** — 회사 영역 안 best_hour 자동 적용
  - **세그먼트 정밀화** — high LTV / 활성 사용자 영역 자동 한정
