### §4-2 외부 규격 확인 (1027 · 원문)
- 우커머스 웹훅 = 원본 소스 [`class-wc-webhook.php`](https://raw.githubusercontent.com/woocommerce/woocommerce/trunk/plugins/woocommerce/includes/class-wc-webhook.php): 서명 = `base64_encode(hash_hmac('sha256', 본문, secret, true))` · 헤더 = `X-WC-Webhook-Source` · `Topic` · `Resource` · `Event` · `Signature` · `ID` · `Delivery-ID` · 성공 = 200~302 · 그 밖(시간 초과 60초 · 연결 실패 포함) = 실패 · **실패가 연속 5번을 넘으면 `disabled`** · **자동 재전송 없음**. 공식 문서 [webhooks](https://developer.woocommerce.com/docs/apis/rest-api/v3/webhooks/)도 「5번 연속 실패 = 꺼짐 · REST 로 다시 켠다」. → 0914 설계서 §6 미검증 중 헤더명 · 인코딩은 닫힘 · 「delivery id 가 재시도마다 새로 나는가」는 재시도 자체가 없다.
- 우커머스 고객 목록 = [REST 문서](https://woocommerce.github.io/woocommerce-rest-api-docs/) 매개변수에 날짜 필터 없음(M12 근거).
