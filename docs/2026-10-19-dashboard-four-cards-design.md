## 2. 칸별 내용

### 2-1. 요금제 현황 (`components/dashboard/PlanStatusCard.tsx`)
- 요금제 이름 · 잠김 / 남은 날 / 체험 만료 배지 · 주의 점 두 번 퍼짐(intro) = **지금 그대로 옮김**.
- AI 크레딧 잔여(누르면 사용 이력 창 · 열 때 원장 다시 읽기) · 고객 DB N명 · 연동 시 매일 분석 N크레딧 = 그대로. 크레딧 미사용 회사 = 「정상 이용 중」 그대로.
- 바닥 묶음:
  - **이번 달 사용금액** = `stats.monthly_cost`(발송 현황 「총 사용금액」에서 옮김 · 값 · 보는 사람 범위 = 서버 그대로).
  - **충전 잔액**(선불만) = `balanceInfo.balance`(대시보드가 이미 읽는 `/api/balance` 값 · 지금은 링크만 있었다) · 누르면 지금 잔액 현황 창. 이름은 그 창과 같은 「충전 잔액」.
  - **에이전트 발송 잔액** = 발송 현황에서 옮김 · 발송ID마다 한 줄 · 1만 원 미만 빨강 · 「잔액 확인 불가」 그대로 · 원장 출처는 줄 `title`.
- 칸을 누르면 `/pricing` 그대로(안의 버튼은 전파 막음).

### 2-2. 발송 현황 (`components/dashboard/SendStatusCard.tsx`)
- 전송 · 성공 · 실패 · 성공률 = 2×2(숫자 16px) · 채널 4개 = 2×2 한 줄(이름 + 숫자).
- 총 사용금액 · 잔액 현황 링크 · 에이전트 잔액 = 요금제 칸으로(§2-1). 숫자 채우기(CountUp) 그대로.

### 2-3. DB 현황 (`components/dashboard/DbStatusCard.tsx` · 칸 → 목록)
- 한 쪽 6개 · 쪽 넘김 · 기준 시각 배지(`formatKstClock(asOf)`) · 상세보기 · 줄 누르면 상세 창(`CardDetailModal`) = 그대로.
- 줄 = 아이콘(지금 카드별 색) · 이름(두 줄까지 단어 단위) · 증감 · 값(한 줄).
- 값 = 지금 표기 규칙 그대로 옮김: count = 명(진행 캠페인 = 건) · rate = 소수 한 자리 % · sum = 1만 이상 「N만원」 · distribution = 1위 항목 수 + 아래 줄 「1위 이름 · 비율」.
- 증감 = `DeltaBadge` 새 선택값 `compact`(화살표 + %만 · %가 없으면 수 · 기준일 title 그대로 · 기본값 동작 그대로).
- 상태 = 미설정 안내 · 미업로드(흐림 + 「고객 DB 업로드」) · 데이터 없음(`-`) = 그대로.
- 첫 화면 들어오기(줄마다 0.06초) · 첫 업로드 공개(dbReveal) · 쪽 넘김 뒤 정지(dbPaged) = 그대로.
- 끝 쪽의 이전 · 다음 버튼은 흐리게 두지 않고 그리지 않는다(LESSONS_FRONTEND 「누를 수 없는 버튼」 · 자리는 비워 둔다).

### 2-4. 오늘의 추천 (`components/dashboard/TodayRecommendCard.tsx`)
- 데이터 = 기존 `GET /api/ai/operator/self-diagnosis`(SQL만 · AI 0 · 차감 0 · 대시보드를 열 때 1회).
  브리핑(매일 오전 일일 분석)이 있으면 그것 · 없으면 규칙 추천 = **AI 한줄로 화면 추천 띠와 같은 판정**(공용 `lib/hub-recommend.ts`로 옮겨 두 화면이 같이 쓴다(서버 호출이 든 공용 요청 모듈 = lib · 10-16 `lib/studio-api` 선례 · AI 존 보존 시험이 lib 까지 센다)).
- 1순위 = 대상 수(있을 때) · 제목(두 줄까지) · [이 한 줄로 시작].
- 2 · 3순위 = 줄(제목 두 줄까지 · 아래 줄 = 대상 수 · 채널 추천).
- 누르면(1순위 버튼 · 줄 · 추천 창 버튼 모두 같은 분기 `hubRecAction`):
  - 기본 = AI 한줄로 입력창에 그 한 줄을 채워 연다(기존 넘기기 키 `ai_operator_prefill_objective` · DB 상세 창과 같은 길).
  - 여정 굳히기 = 여정 화면(`journeyObjectivePrefill`) · 이메일 추천 = 이메일 화면 · 모바일 DM 추천 = DM 화면.
- 모두 보기 = AI 한줄로 화면과 **같은 추천 창**(공용 `components/ai-line/HubRecommendModal.tsx`로 옮김 · 회사 점수 · 진단 우선 항목 · 추천 3장 · 자동 마케팅 현황).
- 보는 사람: 담당자에게 회사 전체 숫자를 숨기는 서버 규칙(`briefForViewer`) 그대로.
- 상태:
  - 읽는 중 = 자리 표시(높이 고정).
  - 잠김 = 구독 만료 · 정지 → 잠김 창 · 요금제가 AI 를 못 씀(`fetchAiOperatorAccess` false 또는 서버 403) → AI 한줄로 소개 창 = **AI 한줄로 버튼과 같은 갈래**.

  - 추천 0 = 「오늘은 새 추천이 없어요」 + AI 한줄로 시작.
- Source caption = 「매일 오전 일일 분석(날짜)」 / 「회사 실측 신호(일일 분석이 쌓이기 전 기본 추천)」.
