# 이폴리움 연동 진행 — 고도몰 SDK + 네이버 스마트스토어

> 작성 2026-06-03. 이폴리움 = 고도몰(독립몰, 고객DB도 고도몰) + 네이버 스마트스토어 병행.
> 연동 2경로: 고도몰 = SDK 브라우저 ingest / 스마트스토어 = 네이버 커머스 API (D178, CT-30 `naver-commerce-client.ts`).

---

## 1. 네이버 스마트스토어 (커머스 API) — 한줄로 개발사 계정  **[신청중]**

### 현황 (2026-06-03)
- **한줄로 명의 스마트스토어센터 가입신청 완료** — 가입심사 3영업일 이내, 결과는 메일/SMS 통보.
- 사유: 네이버 커머스 API 개발업체 계정은 "로그인 커머스ID가 스마트스토어센터 **통합매니저** 권한"일 때만 생성 가능 → 한줄로 자체 스토어 1개로 통합매니저 자격 확보 목적.
- 이 스토어/개발사 계정은 **한줄로 1개·1회**. 고객사마다 만드는 것이 아님.

### 심사 승인 후 (한줄로가 진행)
1. 통합매니저 권한 확인 → 네이버 커머스 API 센터에서 **개발업체(애플리케이션) 계정 생성**.
2. **client_id / secret 발급** → 운영 `.env`:
   `NAVER_COMMERCE_CLIENT_ID` / `NAVER_COMMERCE_CLIENT_SECRET` / `NAVER_COMMERCE_REDIRECT_URI`
3. 네이버 콘솔 등록: redirect_uri `/api/naver-commerce/oauth/callback` + Webhook `/api/naver-commerce/webhook` + scope(주문·회원 조회).
4. `naver-commerce-client.ts` 주석 "콘솔 최종 검증 필요" — authorize/token endpoint URL·scope·토큰 TTL 실값 검증.

### 그 후 (고객사별, 코드 이미 구현됨 — D178)
- 고객사가 한줄로 관리자 → "네이버 스마트스토어 연동" 클릭 → 네이버 OAuth 권한 위임.
- 멀티 테넌트: `company_integrations`에 회사별(`company_id`) + 스토어별(`mall_id`) 토큰 분리 저장. Webhook은 storeId→company 역매핑. 토큰 자동 갱신.
- 고객사 요청 항목: 스마트스토어 **storeId** + **판매자 계정**(OAuth 위임) + **유료 요금제**.

## 2. 고도몰 (SDK 브라우저 ingest) — 즉시 진행 가능

### 한줄로(우리)가 할 것
- 이폴리움 회사에 **CDP public key (`hjl_`) 발급**.
- **SDK 설치 스니펫** + 고도몰 회원ID data-attr(`{=gSess.memNo}`) 삽입 가이드 전달.
- AI 오퍼레이터 → 자사몰 연동 → **"수집 허용 도메인"에 고도몰 도메인 등록**(`cdp_allowed_origins`). CDP 키(`hjl_`)도 같은 화면 **"CDP 키 발급"**에서 발급.
- 전제 확인: 운영에 `companies.cdp_allowed_origins` / `cdp_events` ALTER 적용 + **비즈니스(CDP) 요금제**.

### 고객사(이폴리움)에 줄 것 / 요청할 것
- **줄 것**: `docs/고도몰_SDK_설치가이드.md` 전달 (CDN 스크립트 1줄 + `data-hjl-key` + `<body data-hjl-user-id>` 단계별). 개발자 유무를 묻는 게 아니라 **우리 가이드를 전달** → 그쪽 담당자가 가이드대로 스킨에 삽입.
- **요청할 것**: ① 고도몰 자사몰 `https` 도메인(Origin 등록용) ② 가이드 적용 후 회신(설치 완료 통보) ③ 로그인 회원번호(`{=gSess.memNo}`) 노출 가능 여부.

> 한줄로 측 선결: CDN 배포 URL 확정(`app.hanjul.ai/sdk` vs `cdn.hanjul.ai/sdk` 통일) + 서빙 확인 → AI 오퍼레이터 → 자사몰 연동에서 `hjl_` 키 발급 + 수집 허용 도메인 등록.

## 공통
- 두 경로 모두 **유료(CDP/비즈니스) 요금제** 게이팅.
- **고도몰**은 지금 바로 진행 가능, **스마트스토어**는 한줄로 개발사 계정(스토어 심사) 승인이 선결.
