## 3. 틀 = 모든 메뉴가 같은 것 (부품이 소유)

### 3-1. 소유 구조
- **부품** `components/zone/` — `ZoneFrame`(바닥·머리·띠·명령 카드·차단 상자·강조 자리·본문 폭) · `ZoneHeader` · `ZoneCommand`(한 줄 입력형 / 일반형) · `ZoneEmphasis` · `ZoneBlock` · `ZoneRowActions` · `ZoneSource`. **className prop 없음**(탈출구가 곧 재분열 경로). 머리 보조 동작·대안 개수는 타입(튜플)로 제한.
- **값** `utils/operator-ui.ts`(`OUI_*`, JSX 없는 .ts · 백엔드 테스트가 import) — 밝은 값으로 전면 교체. 콘솔과 같은 값은 `console-ui.ts`에서 가져와 다시 내보낸다. `make-ui.ts`(`MK_*`)도 같은 밝은 값으로.
  - 회의 수렴안은 "console-ui.ts 안 CUI_ZONE_* 구획"이었으나, 25개 소비 파일의 import 이름만 바뀌고 화면 차이가 0이라 기존 파일 이름을 유지한다(값의 원장은 여전히 한 곳).
- **원장** `constants/ai-operator-modules.ts` — 허브 카드와 메뉴 머리가 **같은 객체**를 읽는다(label·icon·gradient·description·path + `id` · `oneLine?` · `tabs?`).
- **톤 문맥** `SurfaceToneContext` — `ZoneFrame`이 'light'를 내려 주고, AI 존 밖에서도 쓰는 공용 창(ConfirmModal·CreditConfirmModal 등 15)은 이 값을 읽어 밝게 뜬다. 문맥이 없으면 지금처럼 짙게(존 밖 회귀 0).

### 3-2. 위에서 아래 순서 (시작 모드: 목록·보드·보고)
1. **남색 머리 띠** `#0F172A`(slate-900) + 비블러 방사 빛 1 · 높이 64(모바일 56) · 바탕 전폭 · 안쪽 폭 1240(CUI_WRAP 값) · sticky.
   `[← 36 · aria "{부모}로"] [타일 40] [제목 18 semibold · 부제 13(md 이상)] … [보조 글자 버튼 ≤1] [? 도움말] [⋯]`
   탭이 있는 메뉴는 띠 둘째 줄(40)에 흰 글자 탭(주소가 탭을 소유). 머리에 두지 않는 것: 새로고침·기간 칩·NEW·상태 뱃지·크레딧 칩.
2. **명령 카드**(허브 명령 카드 축소판) — 띠가 머리 아래로 28px 이어지고 흰 카드가 그 경계에 걸친다. 2겹 그림자.
   - 한 줄 입력형(D3 7메뉴): 1행 = 워드마크 "한줄로" + 밑줄 입력(15px) + 오른쪽 끝 버튼(AI 생성 = 앰버). 2행 = 상태 숫자 · 확인할 것 · 다른 방법(1클릭 칩) · 기준 시각·다시 읽기.
   - 일반형(나머지 5): 1행 = 상태 숫자 · 확인할 것 + 오른쪽 끝 1차 버튼(인디고). 2행 = 다른 방법 · 기준 시각(있을 때).
   - **새로고침은 전 메뉴 이 카드의 "다시 읽기" 한 곳.**
3. **차단 상자**(있을 때만) — 켜기·발송·표시를 막는 조건(발신번호 미등록 · 회사 메일 미연결 · 요금제 잠금 · 고객 데이터 없음)은 명령 카드 바로 아래 전폭 한 줄 + 조치 버튼 1. 막지 않는 것만 "확인할 것" 글자 링크.
4. **강조 카드** ≤1 — 지금 결정할 것이 있을 때만(다음 수+오늘의 여정 기회 · 일일 브리핑 · 월 결재 · 빠른 시작 · 추천 액션). 흰 카드 + 기능 카드 그림자 + 표지(AI 추천 = 앰버 반짝 28 / 결재·조치 = 상태 점 + 같은 색 왼쪽 선 3px). 내용은 기존 JSX 그대로(보이는 개수·1클릭 유지). **유료 AI는 자동 호출하지 않는다**(버튼 "· N크레딧").
5. **거름 칩**(h-8 + 개수가 있을 때만) · 정렬만 select.
6. **작업면**(메뉴 본연의 것 · §4). 틀 부품은 작업면 안쪽(달력 칸·흐름도·차트·폰 미리보기·포스터 무대)의 구조를 바꾸지 않는다. 색만 밝게 옮긴다(§5).
7. **목록 행**: min 60 · `[리드 36] [이름 14 semibold + 상태 칩(점+글자)] [지표 12.5 "라벨 값"] … [대표 1] [보조 ≤1] [⋯]`. 위험 동작은 ⋯ 맨 아래 빨강. 아이콘만 있는 버튼은 닫기·⋯·펼침·이전/다음만(aria 필수). 모바일은 보조를 ⋯ 첫 줄로.
8. **출처** — 카드·차트별로 유지하고 모양만 `text-[10px] italic text-slate-400` + 한국어 "출처: …"(테이블명·영문 제거).

**만드는 중 모드**(편집기·흐름): 같은 머리 띠. 편집기 = 제목 인라인 수정 + 저장 상태 + 오른쪽 끝 1차. 흐름 = 본문 768 왼쪽 정렬 + 하단 확정 바(안쪽 폭 1240, 확정 버튼 x = 명령 카드 버튼 x).
