## §2 결정

1. **템플릿 = 코드 상수 4종** `backend/src/utils/design-core/line-templates.ts` `LINE_TEMPLATES` — 신상품 공개 · 빅세일 · 계절 안내 · 특별 이벤트. 기존 `CORE_GOLDEN_TEMPLATES` · `compileTemplateFor*` 는 쓰지도 고치지도 않는다. DDL 0.
2. **구조는 템플릿이 소유** — 장(기 · 승 · 전 · 결)과 섹션을 템플릿 조립 함수가 정한다. 범용 장 나누기 · 비주얼 디렉터 · 아웃리치 룩 · 생성 뒤 재료 끼우기 · 1017 대표 사진 대체를 템플릿 경로에서 부르지 않는다. 재료가 비면 자리표시 대신 **변형**(장 수 · 블록 자체를 바꿈)을 생성 전에 고른다.
3. **AI 는 닫힌 문구 칸만** — 생성 1회 · JSON(키 = 템플릿 문구 칸 · 칸마다 글자 상한) · 원문(한 줄 · 답 · 그대로 쓰기 켠 페이지 문구)에 없는 숫자나 혜택이 생기면 그 칸 = 템플릿 기본 문구(숫자 0). 가격 · 사진 · 링크는 AI 를 지나지 않는다. AI 실패 = 503 · 차감 0.
4. **장 채움(DM 슬라이드)** — 섹션 최상위 `fit:'grow'` 하나(편집기 저장을 지남) · 뷰어가 장 클래스 계산(`dm-page--fill` = 세로 flex · 아래 56px · grow 섹션이 남은 높이 · 최소 140px / grow 없는 장 = `dm-page--center`) · `:has()` 금지 · 키울 수 있는 구도 닫힌 목록 · 슬라이드에 sticky CTA 금지 · 한 섹션 상품 2개 이하(3 = focus).
5. **대표 사진** = 올린 사진 → 이벤트 페이지 배너(폭 600 이상 · 가로/세로 0.8 이상) → 없음. 없음 + 상품 2개 이상 = 글자 표지 · 상품 1개 = 상품이 곧 표지(상품 장 뺌). 한 결과물 안 같은 사진 1회(원래 주소 기준).
6. **재료 단계** = 1017 단계 모달 재사용 · 템플릿 필수 칸 중 모르는 것만 · 상한 4(필수는 미루지 않음 · 템플릿마다 물을 수 있는 필수 3개 이하 = 등록 관문) · 상품 = **한 단계에서 여러 개**(낱말 탭 · 찾기 · 직접 넣기 + 상품 링크) · **이벤트 페이지 단계**(주소 붙여넣기 → AI 0 읽기 → 배너 · 문구 「그대로 쓰기」).
7. **화면** = 껍데기 하나에 판 둘(고르기 판: 추천 템플릿 예시 큰 화면 · 배치 전환 · 템플릿 줄 / 재료 판: 단계 + 고른 템플릿 예시) · 폭 min(1040, 100vw−48) · 예시 = 같은 조립 함수 + 같은 렌더러 + 가상 업체 고정 재료(사진 = 저장소에 이미 커밋된 정물 사진 재사용).
8. **생성 뒤 배치 전환** = 서버 호출 없이 편집 스토어 안 동기 순수 함수(섹션 `tpl_slot` = 장 키 `p{n}`)로 다시 묶기 · 템플릿 DM 표식 = `template_id = 'line:<id>'` · 템플릿 DM 은 카탈로그 보기 · 장 추가를 숨긴다.
9. **돈** = 1017 2안 그대로(생성비 + 한 줄 완성 10 · 같은 날 같은 한 줄 = 생성비) · 시도 지문에 템플릿 · 배치 · 페이지(주소 + 그대로 쓰기 지문) · 고르기 · 예시 · 바꾸기 · 페이지 읽기 · 배치 전환 = 0원.
10. **스위치** `LINE_TEMPLATES_COMPANY_IDS` — `ONE_LINE_STEPS_COMPANY_IDS` 안에서만(좁히기). 고객사로 넓히는 것 = Harold 시각 확인 뒤.
11. **추천** = 서버 규칙(AI 0) · 빅세일 > 신상품 > 특별 이벤트 > 계절 · 걸린 낱말을 이유로 · 안 걸리면 배지 없음.

### §11-2 설계에서 바뀐 것 (구현 중 실측 · 시험 근거)

- **생성 뒤 배치 전환** = 엔드포인트 없이 편집 스토어 `setLayoutMode` 가 템플릿 DM 이면 `regroupLineTemplatePages`(장 키 `p{n}`)로 다시 묶는다(§2-8 대로 · 수렴안의 `/relayout` 은 만들지 않음).
- **장 채움 CSS** = fit 섹션이 있는 DM 의 슬라이드에만 싣는다(`FILL_CSS` 분리 · 옛 DM 출력 바이트 무변경 · 기존 시험 `sales-outreach-look` 이 잡음). 장 채움 표식(`fit`)은 한 페이지형에서도 남긴다(한 페이지형 = CSS 0 · 편집에서 옆으로 넘기기로 바꾸면 그대로 채움).
- **장 구성 실측 정정**(휴대폰 캡처) — 계절 = 표지 → 상품 → 이야기 + 마무리(이야기만 있는 빈 장 제거) · 신상품 = 첫 상품 장이 2개 이하면 소개 글을 그 장 위에(같은 제목 두 번 0) · DM 상품 2개 = 큰 카드 둘 위아래(좁은 두 칸이 장을 채우면 빈칸이 더 큼) · 혜택 · 마감 띠 = 템플릿 주색 바탕 흰 글자(강조색이 어두운 템플릿에서 「마감까지」 글자가 사라졌다) · 사진 없는 이메일 표지 = 낮은 높이.
- **읽기 관문** = `aiAutoBuildEnabled ‖ 템플릿 스위치`(설계 §4 의 단계 스위치보다 좁힘 · 쓰는 곳이 템플릿 단계뿐).
- **인앱 템플릿 = 웹(자사몰)만** — center_modal 블록은 웹 SDK 기준 · 앱 SDK 표시는 미검증이라 앱 채널은 1017 단계 흐름 그대로(추가 과제).
- **직접 상품** = 사진이 있으면 가격 없이도 카드(`lineTemplateManual`) · 1017 나누기는 그대로.
- **템플릿 생성 실패** = AI 503 · 조립 관문 500 · 한국어 문장(`LineTemplateError` · 차감 · 초안 0).

### §11-4 Codex
