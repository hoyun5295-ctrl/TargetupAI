## 3. 제품설명
```
「한줄로」는 기관이 보유한 고객 명단을 바탕으로 발송 대상 추출, 메시지 문안 작성, 발송, 결과 확인을 하나의 화면에서 처리하는 웹 기반 구독형 소프트웨어입니다.

주요 기능
1. 대상 추출: 사용자가 목표를 문장으로 입력하면 AI가 발송 대상 조건을 만들고, 등록된 고객 데이터에서 실제 대상 인원을 조회합니다. 조건에 맞는 고객이 없으면 발송하지 않습니다.
2. 문안 작성: 문자(SMS, LMS, MMS), 카카오 알림톡, 이메일, 모바일 안내 페이지의 문안을 AI가 작성하고 사용자가 수정해 확정합니다.
3. 이미지 생성: 상품 사진을 바탕으로 홍보용 이미지를 만듭니다.
4. 발송 관리: 예약 발송, 발송 전 통신사 스팸 차단 여부 점검, 수신거부 고객 자동 제외를 지원합니다.
5. 결과 분석: 발송 결과, 고객별 수신 이력, 고객 이탈 및 구매 예측, 성과 분석과 다음 캠페인 추천을 제공합니다.
6. 자동화: 가입, 구매 같은 고객 사건에 따라 정해진 순서로 메시지를 보내고, AI가 제안한 캠페인은 사용자가 승인한 뒤에 발송합니다.

보안
다중 인증 로그인, 국외 접속 차단, 주요 작업 기록 보관 기능을 제공합니다.

제공 형태
별도 설치 없이 웹 브라우저로 이용하는 클라우드 서비스(SaaS)이며, 1년 단위로 구독합니다.
```
