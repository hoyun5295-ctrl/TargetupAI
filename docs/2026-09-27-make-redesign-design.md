## §0 30초 요약

- **무엇**: 담당자가 AI·컴퓨터에 서툴러도 DM·이메일을 쉽게, 완성도 높게. 흐름 = **입구 하나("만들기") → 결과 화면(받는 사람이 볼 실물 + 누른 곳만 고치기) → 보내기**. 세밀하게 고칠 때는 **수정 화면**(왼쪽 블록 · 가운데 휴대폰/PC 두 미리보기 · 오른쪽 누르면 바뀌는 버튼). 첫 화면은 **만들기 하나 + 보낸 것 카드칩 + 상세 창**.
- **같은 뿌리**: DM·이메일은 같은 재료(재료 계약 v1) · 같은 결과 화면 · 같은 수정 화면 틀 · 같은 판정. 채널 차이는 렌더러에만.

## §1 불변 원칙 (이 개편이 지켜야 할 것)

1. **렌더러는 건드리지 않는다.** DM 뷰어·이메일 렌더러는 요청 시점 재렌더라 고치면 발행분·예약분이 즉시 바뀐다. 미리보기는 **렌더러 출력을 그대로** 띄운다(세 번째 렌더러 0).
2. **미리보기는 휴대폰·PC 두 개를 함께, 서로 다르게.** 휴대폰 = 받는 사람 대부분의 화면(크게) · PC = 실제 PC 모습(작게 + 크게 보기). DM 일반 = PC 가운데 480 기둥(`dm-viewer.ts:169`) · 이메일 = 본문 600 · 카탈로그 = 휴대폰 슬라이드 + 넘김 효과 / PC 책(효과와 무관 · 상품 칩 없음).
3. **DM·이메일 수정 화면은 칸 배치와 고치는 방법이 같다.** 채널에 없는 동작은 감춘다(LESSONS_FRONTEND 32 · `hiddenFields`).
4. **미리보기 iframe = `sandbox="allow-scripts"`만**(불투명 출처 · 슬라이드·참여형 동작 유지) + `<head>` 첫 자식에 `CSP connect-src 'none'`(열람 비콘 0) + 섹션 탭·스크롤 보존은 `postMessage`(부모는 `event.source === iframe.contentWindow`로 거른다). 주입은 프론트 CT 한 곳.
5. **자동 발행 0.** 발행(100·참여형 120)·이메일 완성(50)은 사람이 [보내기]를 누른 뒤에만. 금액은 먼저 보여 주되(선견적) **누르는 순간 서버 값이 이긴다**.
6. **보내기 잠금은 화면이 아니라 서버가 한다.** 링크 결함 · 채울 자리(placeholder) · 검수 치명(무시 불가)은 DM 첫 발행(`/publish` · `send-to-target` 발행 전)과 이메일 완성·발송(`/complete` · `/send`)에서 같은 CT로 막는다. **이미 발행된 DM의 재발행(주소 복사)·재발송은 막지 않는다**(기존 동작 보존).
7. **판정은 효과를 만드는 함수 앞, 차감 앞.** 발행비 차감 · 완성 차감보다 먼저 잠금을 본다.
8. **생성 회수(차감 0)는 구조가 빈 경우만.** 링크·자리 채우기는 결과 화면 필수 칸 + 보내기 잠금으로(매번 AI 대기를 버리게 하지 않는다).
9. **가격·링크·할인율은 AI를 지나지 않는다 · 몰 값은 상품번호로 재조회**(AI 자동제작 불변 2·3 그대로).
10. **주소 읽기 = AI 0 추출 · 가드 크롤만 · 렌더 대기 0**(워커 점유 중이면 정적 결과). 읽어 온 카드 = **재료**. 할인율·기간을 그대로 쓰려면 담당자가 카드마다 **"이 문구 그대로 쓰기"**를 켠다(기본 꺼짐 · 직접 입력 판과 같은 규칙 = 불변 1 · 끈 카드는 숫자만 빠지고 만들기는 1클릭 그대로). 서버는 행사 진행 여부를 추측하지 않는다(★0927 Codex 3R~12R 결론 · §10). 확인은 기존 크레딧 확인 창 안 도메인 실명 고지 · 감사 기록은 서버 도달 뒤.
11. **쓰던 입구는 지우지 않고 접는다.** 핸들러·상태 무변경, 렌더 분기만. 딥링크 주소(`/dm-builder?id=` · `/email-campaigns?edit=`)는 그대로 둔다(소비처 20여 곳 무변경).
12. **돈 단위·멱등키는 기존 그대로.** 생성 `quick:{c}:{ch}:{token}:{지문}` · 발행 `dm-publish:{id}` · 완성 `email-campaign-complete:{id}`.
13. **모델명 0 · native dialog 0 · 줄표 0 · 내부 코드명 0**(사용자 노출 문구).
