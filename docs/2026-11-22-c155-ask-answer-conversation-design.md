## §2 서버

### S1 요청 꼴(`POST /api/ai-line/ask/answer`)

`{ question, attemptToken, history? }` · `history` = `[{ q, a }]`(앞에서부터 시간순). 검사 한 곳(`readAskHistory`): 배열 · 10개 이하 · 항목마다 글자 둘(`q` 1 ~ 500자 · `a` 1자 이상) · 그 밖 = 400 `HISTORY_INVALID`. 서버가 쓰는 것 = 뒤에서 6개 · `a` 는 1,200자에서 자른다. `history.length ≥ 10` 인 요청 = 400 `THREAD_FULL`(「새 대화로 시작해 주세요」).

### S2 앞 문답을 맥락으로(`utils/citations.ts`)

`callAIWithCitations` 에 선택 인자 `history?: Array<{ q: string; a: string }>` 를 더한다. 있으면 메시지 줄 = `[앞 질문, 앞 답] × n` 뒤에 **문서 + 이번 질문**(문서는 이번 질문 메시지에만 붙는다 = 근거는 지금 문서). 없으면 지금과 같은 요청(옛 실험실 주소 무변화). 시스템 글에 한 줄을 더한다(대화일 때만): 「앞 문답은 맥락이다. 숫자와 사실은 이번에 받은 document 에서만 답한다. 앞 답의 숫자가 이번 document 와 다르면 이번 document 가 옳다.」

### S3 한 번만 걷기

`askAnswerKey(회사, 시도 표, 질문, history)` = 지문에 앞 문답(서버가 실제로 싣는 6개 · 자른 뒤 글)을 넣는다. 화면은 문답마다 새 시도 표를 쓴다(같은 문답을 다시 누르면 같은 표 = 다시 걷지 않는다 · 지금 규칙 그대로).

### S4 표의 숫자 열

`AskTable` 에 선택 칸 `chart?: { unit: string; labels: string[]; series: Array<{ name: string; values: Array<number | null> }> }`:
- **자리 맞춤**: `labels` · 각 계열의 `values` 는 `rows` 와 같은 줄 수 · 같은 차례다(줄 i 의 이름 = `labels[i]` · 값 = `values[i]`). **`null` = 재지 않은 값**(표의 「—」)이고 0 은 잰 0건이다 — 둘을 섞지 않는다.
- 고객 묶음 = `받을 수 있는 분`(명) 한 계열 · 채널 = `발송`(건) 한 계열 · 상품 = `조회 · 장바구니 · 구매` 세 계열(매장 상품의 조회 · 장바구니 = `null` · 구매는 숫자 = 지금 표가 「—」로 적는 자리와 같다 `ask-answer.ts` 103 ~ 107) · 흐름 = `건수` 한 계열(단계 순서).
- 근거 문서로 넣는 글(`askTablesAsDocs`)은 지금 그대로 `rows`(글자 표)다 = 답의 근거가 바뀌지 않는다.

## §3 화면(`AiAskPage.tsx` 답 화면 · 조각은 `components/ai-ask/` 로 뺀다)

- **3-A 대화**: 답 화면 = 문답 줄(위에서 아래로 · 질문 = 오른쪽 말풍선 꼴이 아니라 지금 제목 꼴 유지 · 답 = 지금 답 상자). 맨 아래 = 입력 칸 「이어서 묻기」 + 단추 「묻기 5크레딧」 + 다음 질문 칩. 답을 받는 동안 입력 · 단추 잠금 + 「답을 쓰고 있어요」 줄(지금 글). 실패 = 그 문답만 오류 줄(앞 문답은 남는다 · 낸 답을 버리지 않는다).
  - 뒤로 = 대화를 닫고 처음 화면(대화가 2문답 이상이면 「대화를 닫을까요? 받은 답은 다시 볼 수 없어요」 확인 창 · `ConfirmModal`).
  - 10문답 = 입력 칸 자리에 「대화가 길어졌어요. 새 대화로 시작해 주세요」 + 단추.
  - 분류코드로 나뉜 담당자 = 지금 안내 그대로(첫 문답에서 막힌다).
- **3-B 그래프**: 표 제목 줄 아래 막대 그래프(가로 막대 · 줄 수 8 이하 · 값 라벨 · 모바일 폭 320 에서 넘침 0) → 그 아래 지금 표. `null` 값 = 막대를 그리지 않고 값 자리에 「—」(풍선 글도 「—」) · 0 = 길이 0 막대 + 「0」. 상품 표 = 묶은 막대 셋. 색 = 화면 토큰(검정 · 회색 · 주황 하나).
- 접힘: 앞 문답의 표 묶음 = 「표 3개 보기」 한 줄(누르면 펼침).
