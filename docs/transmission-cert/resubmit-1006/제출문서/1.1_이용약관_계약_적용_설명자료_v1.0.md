## 3. 확인 · 동의 절차 (확인사항 ④)

- 고객사는 서비스 이용 계약을 서면으로 체결하고, 당사는 계약 확인 뒤 계정을 발급한다. 공개 회원가입 화면이 없으므로 「가입 단계 동의」는 계약 체결로 이루어진다.
- 이용약관은 로그인 화면에서 항상 열람할 수 있다.
- 로그인 화면에서 다중인증 · 발신 인증 · 본인확인 의무화를 사전 고지하고 있다(2026-10-26 시행).
