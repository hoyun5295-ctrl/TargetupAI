## 3. 증빙 파일 읽는 법

- H 로 시작하는 파일은 한줄로, E 로 시작하는 파일은 비토 게이트웨이(사설발송 엔진)의 증빙이다.
- 「로그 원문 발췌」는 운영 데이터베이스 · 서버에서 조회한 출력을 값을 고치지 않고 옮긴 것이다. 고객사 식별값과 외부 주소 끝자리만 같은 길이의 별표로 가렸다.
- 각 파일 머리에 대상 시스템 · 수집 시각 · 수집 방법이 적혀 있다.
