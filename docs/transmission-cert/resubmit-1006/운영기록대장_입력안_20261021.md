# 운영 기록 대장 입력안 · 2026-10-21 (사설 원격 접속망 해제)

출장 때 켠 사설 원격 접속망이 귀국 뒤에도 두 서버에서 켜져 있었다(2026-10-21 실사 준비 점검에서 발견 · 결함 대장 D-19).
그날 두 서버 모두 끄고 .62 방화벽의 출장용 줄을 지웠다. 이 입력안은 [10/06 입력안](운영기록대장_입력안_20261006.md) 1~4번의 빈칸(출장 기간 · 해제 시각)을 실측값으로 채운 것이다.

- 출장 기간 = 2026-10-08 ~ 10-12(Harold 10-21).
- 해제 실측(Harold 실행 10-21) = 서비스 정지 · 자동 시작 해제 → `inactive` · `disabled`. 정지 시각(서비스 기록) = 10:12:45(.62로 봄) · 10:12:58(.65로 봄). 붙여 준 순서로 서버를 정했다 · 반대면 두 시각만 바꾼다.
- .62 방화벽 `trip-tailscale-ssh` 줄 삭제 → 정책 파일 수정 2026-10-21 10:13:52 · .65 에는 그런 줄 없음.
- 두 서버 접속 기록(`last`)의 100.x 출발지 = 100.116.151.70(대표 노트북) 하나 · 10-08 ~ 10-11 23:07 · 그 뒤 0건.
- 1 · 3번 시각과 근거는 10/06 입력안에서 옮겼고 이번에 다시 확인하지 않았다. 10/06 기록이 대장에 이미 있으면 1 · 3번은 등록하지 않는다.
- 4번 「접속망 접근 규칙에서 한줄로 서버 제거」는 Tailscale 관리 콘솔 grants 정리를 마친 뒤에만 쓴다.

입력 위치 = 슈퍼관리자 → 보안 · 인증 → 운영 기록 대장 → 「+ 방화벽 정책 변경」 · 확인은 작성자와 다른 관리자.
