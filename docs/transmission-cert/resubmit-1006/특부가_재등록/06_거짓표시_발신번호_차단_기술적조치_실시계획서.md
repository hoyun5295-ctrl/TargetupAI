# 거짓으로 표시된 발신번호의 문자메시지 차단을 위한 기술적 조치 실시계획서

주식회사 인비토 · 한줄로(hanjul.ai) · 비토 게이트웨이

| 작성일 | 시행일 |
|---|---|
| 2026-10-05 | 2026-10-06 |

## 1. 목적과 근거

거짓으로 표시된 발신번호로 문자메시지가 발송되지 않도록, 발신번호를 등록 단계와 발송 단계에서 두 번 거르고, 거짓 표시 번호로 발송한 회원 계정의 발송을 막는다.

- 「전기통신사업법」 제84조의2(전화번호의 거짓표시 금지 및 이용자 보호)
- 「거짓으로 표시된 전화번호로 인한 이용자의 피해 예방 등에 관한 고시」 제10조(발신번호 사전등록) · 제11조(사설문자발송장비 발신번호 거짓표시 확인) · 제12조(서비스 제공의 중지)
- 한국인터넷진흥원 「거짓으로 표시된 전화번호로 인한 이용자 피해 예방 등에 관한 세부지침」 제13조제4항(발신번호 등록 규칙) · 제16조(발신번호가 변작된 인터넷발송 문자메시지 차단)

## 2. 적용 대상

| 시스템 | 발송 경로 |
|---|---|
| 한줄로 | 웹 발송 화면 · API |
| 비토 게이트웨이 | 고객사 사설발송 연동(발송 에이전트 · API · 규격연동) |

## 3. 발신번호 사전등록

1. 이용자가 발신번호를 신청하면 통신서비스 이용증명원 · 재직증명서 · 위임장 등 증빙을 받아 당사 관리자가 확인한 뒤 승인한다. 승인한 번호만 등록된다.
2. 등록된 번호로만 발송된다. 한줄로는 발송 직전에 회신번호가 그 회사의 등록 번호인지 확인하고, 게이트웨이는 고객사 승인 발신번호 목록과 대조해 목록 밖이면 발송 전에 실패 처리한다.
3. 등록 · 심사 · 배정 기록(신청자 · 서류 · 심사자 · 심사 일시 · 반려 사유)이 신청 건마다 남는다.

## 4. 발신번호 규격(세칙) 필터링 규칙

세부지침 제16조 · 제13조제4항의 규격에 맞지 않는 번호를 차단하는 규칙을 시스템에 적용한다.

| 구분 | 규칙 |
|---|---|
| 기본 | 발신번호 전체 번호수가 8~11자리인 경우에만 허용한다. 숫자 외 문자가 들어간 번호는 차단한다(하이픈 · 공백 · 괄호 · 점 구분 표기는 허용). |
| 대표번호(15YY · 16YY · 18YY) | 전체 8자리인 경우에만 허용한다. |
| 030 · 050 으로 시작하는 번호 | 전체 12자리까지 허용한다. |
| 특수번호(112 · 1335 등) | 국가 · 지방자치단체 · 공공기관 이용자에 한해 허용하는 번호다. 당사 이용자는 계약 법인이고 공공기관 이용자가 없어 전부 차단한다. |
| 유선전화번호 | 지역번호를 포함해야 한다. 지역번호 없이 시작하는 번호는 차단한다. |
| 이동전화번호 | 010 번호는 010-ABYY-YYYY 형식(11자리)만 허용한다. |
| 지역번호 결합 | 대표번호(15YY · 16YY · 18YY)와 공통서비스식별번호(0N0 계열) 앞에 지역번호를 붙인 번호는 차단한다. |

규칙은 세 지점에서 같은 판정으로 적용한다.

| 적용 지점 | 동작 |
|---|---|
| 발신번호 등록 · 신청 접수 · 승인 · 번호 변경 · 대량 등록 | 규격 위반 번호는 등록되지 않고 사유를 화면에 표시한다. |
| 한줄로 발송 직전(캠페인 발송 · 직접 발송) | 회신번호가 규격에 맞지 않으면 발송을 시작하지 않는다. |
| 게이트웨이 발송 직전 | 고객사 승인 발신번호 대조와 같은 자리에서 규격을 판정하고, 위반이면 발송 전에 실패 처리해 발송 기록에 발신번호 오류로 남긴다. |

사전등록 예외로 승인한 고객사(특수한 유형의 부가통신사업자 등 · 승인 사유를 기록)는 그 사업자가 자기 이용자의 발신번호 사전등록과 규격 확인 의무를 지므로, 게이트웨이의 사전등록 대조와 규격 판정을 하지 않는다. 예외 승인과 해제는 감사 기록에 남는다.

## 5. 거짓 표시 번호로 발송한 회원 계정 조치

1. 사전 차단: 등록되지 않은 번호와 규격 위반 번호는 3 · 4절에 따라 발송 단계에서 걸러져 문자메시지가 나가지 않는다.
2. 인지와 확인: 중계사업자의 차단 통보, 한국인터넷진흥원 · 중앙전파관리소의 요청, 수신자 신고로 거짓 표시가 의심되면 발송 기록으로 발송 계정 · 발신번호 · 일시를 확인한다.
3. 서비스 제공 중지(고시 제12조): 거짓 표시가 확인되면 해당 발송 계정의 서비스를 일시 중지한다. 중지하기 전에 담당자에게 중지 사유와 이의제기 절차를 전자우편 · 문자로 통지한다. 계정을 중지하면 시스템이 접속 중인 세션을 즉시 끊고, 담당자 휴대폰으로 조치 사유를 문자로 자동 고지한다.
4. 발신번호 정리: 거짓 표시에 쓰인 번호는 등록을 해제한다.
5. 해제: 위반 원인 소명 · 재발 방지 서약을 받은 뒤 책임자 승인으로 해제한다(「불법스팸 발송 방지계획서」의 조치 절차와 같다).
6. 기록: 조치 일시 · 처리자 · 대상 계정 · 사유가 감사 기록에 남고, 1년 이상 보관한다.
