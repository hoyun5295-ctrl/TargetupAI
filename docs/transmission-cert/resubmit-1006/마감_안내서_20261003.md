### 조회 1 · 발송 원장 보관 기간 (#16 근거)

**실행 위치: .62 한줄로 서버 · root** (DB 비밀번호를 묻으면 smsuser 비밀번호 입력)
```bash
docker exec -it targetup-mysql mysql -usmsuser -p smsdb -e "SELECT MIN(RIGHT(table_name,6)) AS oldest_month, MAX(RIGHT(table_name,6)) AS newest_month, COUNT(*) AS log_tables FROM information_schema.tables WHERE table_schema='smsdb' AND table_name REGEXP '^SMSQ_SEND_[0-9]+_[0-9]{6}$';"
```
보는 것: 가장 오래된 월별 발송 기록이 아직 남아 있는지. 우리 코드에는 이 기록을 지우는 곳이 없습니다(1003 확인).

### 조회 2 · 발신번호 자체 등록이 켜진 고객사 (#17 근거)

**실행 위치: .62 한줄로 서버 · root**
```bash
docker exec -i targetup-postgres psql -U targetup -d targetup -c "SELECT company_name FROM companies WHERE allow_callback_self_register = true ORDER BY 1;"
```
보는 것: 켜진 고객사가 몇 곳인지. 켜진 곳은 고객사 관리자가 증빙 심사 없이 번호를 등록합니다.

### 조회 3 · D-8 스위치를 켜면 막히는 고객사 (#25 근거)

**실행 위치: .62 한줄로 서버 · root**
```bash
docker exec -i targetup-postgres psql -U targetup -d targetup -c "SELECT COALESCE(subscriber_type,'(미설정)') AS 유형, COUNT(*) AS 회사 FROM companies GROUP BY 1 ORDER BY 1;" -c "SELECT c.company_name, COALESCE(c.subscriber_type,'(미설정)') AS 유형, c.mobile_line_limit AS 회사설정_무선, COALESCE(a.n,0) AS 활성계정, COALESCE(a.n,0)*4 AS 켜면_무선상한, COALESCE(m.n,0) AS 무선보유 FROM companies c LEFT JOIN (SELECT company_id, COUNT(*) AS n FROM users WHERE is_active = true AND COALESCE(is_system,false) = false GROUP BY 1) a ON a.company_id = c.id LEFT JOIN (SELECT company_id, COUNT(*) AS n FROM callback_numbers WHERE regexp_replace(regexp_replace(phone, '\D', '', 'g'), '^82', '0') ~ '^01[016789][0-9]{7,8}$' GROUP BY 1) m ON m.company_id = c.id WHERE COALESCE(m.n,0) > 0 ORDER BY (COALESCE(m.n,0) > COALESCE(a.n,0)*4) DESC, m.n DESC;"
```
보는 것: 법인 중 「무선 보유 > 활성 계정 × 4」인 곳(켜면 새 무선 번호 등록이 막힘 · 기존 번호는 그대로), 유형 미설정 회사 수(미설정 회사에는 스위치가 걸리지 않음).

### 조회 4 · 엔진 발신번호 예외 정책을 쓰는 고객사 (#23 근거)
