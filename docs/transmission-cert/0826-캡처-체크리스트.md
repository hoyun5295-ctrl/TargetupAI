## ⛔ 남은 위험 2가지

**1. 허용 대역 60개는 캡처용 표본이지 전량이 아니다.** (2026-08-27 23:14 해결분 = 1개 → 60개)
APNIC KR 목록에서 앞 60줄만 넣었다. 캡처는 이걸로 충분하지만 **전량은 아니다.**

⚠ **이 상태에서 `GEO_BLOCK_ENFORCE_FROM`을 켜면 그 60개 밖의 정상 국내 사용자가 전부 막힌다.**
시행 전 순서는 원장 §4-G 「시행 전 남은 것」 그대로다: 전량 적재 → 탐지 기간 운영 → 해외 본사 고객사 예외 등록 → 그때 스위치.
전량은 수천 줄이라 화면 붙여넣기가 현실적이지 않다. 시행 준비 때 서버 직접 적재 경로를 별도로 만든다.

**2. 탐지·차단 결과 로그가 비어 있다.**
「국외 접근 기록이 없습니다」가 사실이다(국외 접속이 실제로 없었다). 거짓이 아니므로 그대로 내되,
설명자료에 "탐지 기간 운영 중이며 현재까지 국외 접근 0건"을 적어 빈 화면의 이유를 함께 낸다.
