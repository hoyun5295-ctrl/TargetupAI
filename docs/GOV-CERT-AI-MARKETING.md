- 등급: 1등급 = 품질평가 80점 이상(제품설명서 · 사용자취급설명서). 2등급은 별개 등급(품질 60% + 업무적합성 40%, 70점)이라 거치지 않는다. 실행 시험은 사실상 같다.
- 비용 · 기간: 정찰가 없음(사전상담 견적). 시험 2~4주 · 대기는 2024년 6개월 보도 뒤 단축 대책 → 현재 미검증.
- 준비 원칙
  1. 시험 범위 = 고객사 화면(한줄로 웹 서비스)으로 좁힌다. 슈퍼관리자 · 내부 도구 제외.

  3. 문서는 실제 화면 · 기능에서 옮긴다(문서 ≠ 동작 = 결함).
  4. 시험 전 8대 품질특성(기능적합성 · 성능효율성 · 호환성 · 사용성 · 신뢰성 · 보안성 · 유지보수성 · 이식성) 자체 예비 시험.
  5. 시험 환경 = 시험 계정 · 합성 데이터 · 시험 발송 경로(실고객 데이터 0).
