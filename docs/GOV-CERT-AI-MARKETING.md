- 준비 원칙
  1. 시험 범위 = 고객사 화면(한줄로 웹 서비스)으로 좁힌다. 슈퍼관리자 · 내부 도구 제외.

  4. 시험 전 8대 품질특성(기능적합성 · 성능효율성 · 호환성 · 사용성 · 신뢰성 · 보안성 · 유지보수성 · 이식성) 자체 예비 시험.
  5. 시험 환경 = 시험 계정 · 합성 데이터 · 시험 발송 경로(실고객 데이터 0).
