# 모티브이노베이션 · 인비토 문자 연동 진행 의견안

수신: 주식회사 모티브이노베이션 채희웅 대표님\
발신: 주식회사 인비토 (한줄로)\
일자: 2026년 10월 15일

## 1. 요약

오너뷰에 문자 발송 기능을 붙이는 방법을 두 가지 안으로 정리했습니다.
두 안을 가르는 기준은 하나입니다. **모티브이노베이션이 고객사로부터 문자 이용 대금을 직접 받는가**입니다.

| 구분 | 1안. 재판매 사업자로 직접 운영 | 2안. 인비토 직접 계약과 파트너 정산 |
|---|---|---|
| 문자 대금 수납 | 모티브이노베이션 | 인비토 (고객사가 직접 선불 충전) |
| 필요한 자격 | 특수한 유형의 부가통신사업자 등록, 전송자격인증 | 없음 |
| 계정 발급 | 모티브이노베이션이 직접 | 모티브이노베이션 요청, 인비토 승인 후 발급 |
| 제공 화면 | 비토콘솔 (문자 발송 전용 웹) | 한줄로 |
| 오너뷰 연동 | 오너뷰 로그인으로 비토콘솔 접속 | 오너뷰 로그인으로 한줄로 접속 |
| 이용자 인증 | 본인인증, 로그인 다중인증, 발송 추가 인증 (모티브이노베이션이 직접 운영) | 본인인증, 로그인 다중인증, 발송 추가 인증 (한줄로가 적용) |
| 모티브이노베이션 수익 | 판매 마진 | 소개 고객사 확정 사용액 기준 수수료 |
| 시작 시점 | 두 자격 취득과 연동 개발 이후 | 연동 개발 이후 |

## 2. 대금을 직접 받으려면 자격이 필요한 이유

고객사로부터 문자 이용 대금을 받고 그 고객사의 문자를 보내 주는 것은 문자 발송 서비스를 판매하는 일입니다.
이 사업을 하려면 **특수한 유형의 부가통신사업자로 등록**해야 하고, 대량 문자를 발송하는 사업자는 **방송미디어통신위원회 고시에 따른 전송자격인증**까지 받아야 합니다.

인비토는 실제 발송 주체와 직접 계약을 맺은 계정에만 발송을 허용합니다.
자격이 없는 사업자가 인비토 계정 하나로 여러 고객사의 문자를 대신 보내고 대금을 받는 구조는 인증 기준상 받아들일 수 없습니다.
따라서 두 자격이 없는 상태에서는 2안 구조로만 진행할 수 있습니다.

## 3. 두 자격의 준비 난이도

### 3-1. 특수한 유형의 부가통신사업자 등록

등록 심사에서는 정보보호를 위한 기술적 조치 실시계획을 정해진 서식과 실물 증빙으로 제출해야 합니다. 주요 항목은 아래와 같습니다.

| 항목 | 요구 내용 (요지) |
|---|---|
| 정보보호시스템 | 침입차단·침입탐지 시스템, 웹방화벽 설치와 운영, 방화벽 정책 관리(불필요한 전체 허용 금지, 기본 차단), 과부하 대비 부하분산 |
| 취약점 점검 | 연 1회 이상 점검, 결과의 정보보호 최고책임자 보고, 발견 취약점 조치 이력 관리 |
| 접근통제 | 인가된 사람만 접속, 외부 접속 시 일회용 비밀번호 등 보안 설정 |
| 로그 관리 | 시스템과 정보보호시스템 로그의 기간별 보관과 관리 |
| 발신번호 | 거짓으로 표시된 발신번호의 문자 차단 조치 |
| 통신이력 | 문자 발송과 재전송 통신이력 1년 보관 |

붙임 서식만 18종이고, 서식마다 장비 현황표, 정책 화면, 점검 보고서 같은 실물 증빙이 따라붙습니다.
자체 발송 시스템 없이 상위 사업자의 시스템을 쓰는 경우 일부 항목은 상위 사업자와의 계약서와 연동 증빙으로 대신하지만, 접근통제와 보안설정은 직접 갖추고 증빙해야 합니다.

### 3-2. 전송자격인증

방송미디어통신위원회 고시의 인증기준 18개 항목을 심사받습니다.
서류 심사(화면 캡처, 양식, 설명자료)를 통과하면 현장 심사에서 시스템 실물을 확인합니다. 서류로 확인이 어려우면 보완 요청이나 부적합 판정이 나옵니다.

| 영역 | 요구 내용 (요지) |
|---|---|
| 계정 관리 | 실제 발송자 본인확인, 중복 가입 차단, 발신번호 회선 수 제한, 등록·변경·삭제 이력 관리 |
| 국외 이용 통제 | 웹, 관리자, API 등 모든 접근 경로의 국외 접속 차단과 예외 승인 이력 |
| 부정 사용 차단 | 결제 정보와 계정 명의 대조, 불일치 시 보류와 소명 절차, 처리 결과 기록 |
| 시스템 보안 | 경계 방화벽과 정책 변경 이력, 접근권한 분류표와 승인 이력, 인사 변동 시 즉시 회수와 정기 점검 |
| 인증 | 모든 이용자의 로그인 다중인증, 발송 시 발신번호 추가 인증 |
| 로그 | 접속·인증·발송·과금 로그 1년 이상 보관과 변조 방지, 월 1회 정기 점검 기록 |
| 스팸 대응 | 신고 확인과 이용자 조치 및 고지, 키워드·URL·전화번호 조합의 금칙어 자동 탐지와 차단 |

- 웹 발송, API 발송, 설치형 솔루션처럼 서비스 유형마다 증빙을 따로 제출해야 합니다.
- 인증을 받은 뒤에도 신청서 기재사항이 바뀌면 다시 신청해야 하고, 월 단위 점검 기록 같은 운영 의무가 계속됩니다.

### 3-3. 준비에 드는 실제 부담

두 자격은 기능 개발만으로 끝나지 않습니다. 보안 장비와 서버 구성, 내부 운영 대장, 매월 점검 기록까지 실제로 운영하고 있어야 심사를 통과할 수 있습니다.
인비토 역시 이 기준을 갖추는 데 상당한 기간 동안 전담 인력과 보안 인프라 투자가 들었습니다. 문자 발송을 주업으로 하지 않는 회사가 단기간에 준비하기는 쉽지 않은 수준입니다.

## 4. 1안. 재판매 사업자로 직접 운영

**조건**

- 특수한 유형의 부가통신사업자 등록증과 전송자격인증서 사본 제출

**인비토가 제공하는 것**

- **비토콘솔**: 외부 메시징 사업자에게 제공할 목적으로 만든 문자 발송 전용 웹입니다. 모티브이노베이션이 고객사와 사용자 계정을 직접 만들고 관리합니다.
- **오너뷰 연동**: 연동 개발을 통해 오너뷰에서 계정을 만들면 비토콘솔 계정이 함께 생성되어 연결되고, 오너뷰 로그인 상태로 비토콘솔에 접속합니다.

**제공하지 않는 것**

- **한줄로의 AI 마케팅 오퍼레이션 기능은 1안에 포함되지 않습니다.** 1안은 문자 발송 기능만 제공합니다.

**모티브이노베이션이 맡는 것**

- 고객사 계약, 대금 수납, 세금계산서 발행, 고객 응대
- 인증 기준에 따른 운영: 로그 보관과 월 점검, 스팸 신고 처리
- **이용자 본인인증과 발송 추가 인증은 1안에서도 필수입니다.** 전송자격인증 기준이 모든 이용자의 본인확인, 로그인할 때의 다중인증, 이용자가 직접 지시하는 문자 발송의 발신번호 추가 인증을 요구합니다. 1안에서는 모티브이노베이션이 운영 주체로서 모든 이용자 계정에 이 인증을 직접 적용하고 관리해야 합니다.

**별도 협의**

- 발송 단가, 비토콘솔 제공 방식과 이용 조건

## 5. 2안. 인비토 직접 계약과 파트너 정산

**구조**

- 오너뷰 고객사 한 곳이 한줄로 고객사 한 곳이 됩니다. 고객사마다 사용자 계정을 여러 개 둘 수 있습니다.
- 각 고객사는 인비토와 직접 이용 계약을 맺습니다. 문자 이용 대금은 고객사가 인비토에 직접 선불로 충전하고, 세금계산서는 인비토가 고객사에 발행합니다.
- 모티브이노베이션은 문자 대금을 받지 않으므로 별도 자격이 필요하지 않습니다.

**계정 발급 절차**

1. 모티브이노베이션 전용 계정 발급 요청 페이지에서 고객사 정보, 담당자, 적용 단가를 입력해 요청합니다.
2. 인비토 관리자가 내용을 확인하고 승인하면 인비토가 계정을 발급합니다.
3. 발급된 고객사에는 모티브이노베이션 소개 고객사라는 구분값이 붙습니다.

**로그인과 발송 인증**

- 오너뷰에 로그인한 상태에서 한줄로로 바로 접속합니다. 별도 회원가입이나 아이디·비밀번호 재입력이 필요 없고, 접속 후에는 세션이 유지됩니다.
- 다만 인증 기준에 따라 새로 접속할 때 담당자 휴대폰 인증번호 확인은 거칩니다.
- 이용자가 직접 지시하는 문자 발송에는 인증 기준에 따라 발신번호별 추가 인증을 적용합니다. 한 번 인증하면 일정 시간 유지되고, 접속 환경이 바뀌면 다시 인증합니다. 이용자 개입 없는 자동 발송은 제외됩니다.
- **최초 로그인 시 고객사 담당자가 직접 본인인증과 한줄로 이용약관 동의를 진행해야 합니다.** 본인인증은 2026년 10월 26일부터 한줄로 전체 계정에 적용되는 필수 절차입니다.

**사용현황 공유와 정산**

모티브이노베이션 전용 화면에서 소개 고객사별 사용현황을 확인할 수 있습니다.

| 공유하는 정보 | 공유하지 않는 정보 |
|---|---|
| 고객사명, 발급일, 이용 상태 | 메시지 내용 |
| 월별 발송 건수 (문자 유형별) | 수신번호, 고객 정보, 수신거부 명단 |
| 월별 확정 사용액 (발송 실패 환불 반영 후) | 고객사 내부 사용자별 활동 |
| 충전 내역 | 다른 파트너의 고객사 |

- 수수료는 확정 사용액을 기준으로 월 단위로 정산합니다. 수수료율은 별도로 협의합니다.
- 전용 화면의 숫자는 인비토 거래내역서와 같은 집계를 사용합니다.

**이용 범위와 개발**

- 고객사는 한줄로 고객사로서 가입한 요금제에 따라 서비스를 이용합니다.
- 연동 로그인, 전용 요청 페이지, 사용현황 화면은 양사 협업으로 개발합니다. 일정은 협의합니다.

## 6. 인비토 의견

모티브이노베이션이 현재 두 자격을 갖추고 있지 않다면 2안으로 시작하는 것을 권합니다.
자격 준비 없이 연동 개발만으로 시작할 수 있고, 대금 수납과 세금계산서, 인증 기준 운영 부담 없이 수수료 수익을 얻을 수 있습니다.
이후 두 자격을 취득하면 1안 전환을 다시 협의할 수 있습니다.
