### Slide 03 — Problem (한국 마케터의 고통)

- **타이틀**: "한국 마케터는 매일 이런 일을 합니다"
- **3 카드 가로 배치**:
  1. **타겟 추출 — 1~2시간** (DB 쿼리 + 엑셀 + 필터 조합)
  2. **메시지 작성 — 30분~1시간** (브랜드 톤 + 광고 검증 + 채널별 분량)

- 각 카드 = 상단 아이콘 (Clock / Edit / Shield) + 작업 시간 + 짧은 설명
- 하단 **굵은 한 줄**: "캠페인 한 번에 평균 2~4시간 + 매번 같은 흐름 반복 = 마케터의 가장 큰 손해"

### Slide 04 — Solution (한줄로 AI Operator)

- **타이틀**: "자연어 한 줄 = 5~10초 안에 완성된 마케팅 패키지"
- **중앙 큰 영역**: 자연어 입력 박스 mockup (예: "VIP 재구매 유도")
  → 아래쪽 6 카드 흐름 (Trigger Detection / Target Analysis / Message Composition / Compliance Check / Cost-ROI / Schedule Optimization)
  → 최종 **통합 제안서** 카드 (타겟 + 메시지 3안 + 채널 + 시점 + 비용)
- 각 6 카드 = 그라데이션 아이콘 (rose/amber/emerald/cyan/violet/fuchsia 순)
- 하단: "마케터는 검토 + 승인만. AI 단독 발송은 절대 없습니다."

### Slide 05 — 핵심 가치 3축
