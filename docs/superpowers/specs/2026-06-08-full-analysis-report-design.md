# 풀분석 프리미엄 마케팅 분석보고서 — 설계 스펙

- 날짜: 2026-06-08
- 상태: 설계 합의 → 리뷰 대기 (구현 전)
- 영역: 성과리포트(`/performance`) 내 300크레딧 풀분석

## 1. 목적
- 성과리포트에 "풀분석" 신규 기능. 기간 종합 마케팅 분석보고서를 AI가 생성 — 회사 보고서로 써도 손색없는 프리미엄 가치.
- 진입 시 300크레딧 소모.
- 기존 무료 "PDF 보고서" 단독 버튼은 제거(풀분석 결과물 PDF로 흡수).

## 2. 가치 정의 (300크레딧 정당화)
- 무료 대시보드 = 현황 지표 나열, 해석은 사용자 몫.
- 풀분석 = AI가 데이터를 종합해 진단 → 원인 → 처방 → 예측까지 결론을 주는 컨설팅 리포트.
- 전 섹션 그 회사 실측 데이터 기반. 임의 상수(전환율·uplift 등) 금지. 부족 시 "데이터 부족" 정직 표기.

## 3. 보고서 구성 (10섹션)
1. 익스큐티브 서머리 — 1p 요약(결론 + 핵심 발견 3 + 권고 3)
2. 성과 종합 진단 — 핵심 지표 + 전기 대비 + AI 평가
3. 원인 분석 — 세그먼트·채널·시점·메시지 교차 드라이버
4. 고객 세그먼트 심층 — RFM·등급, 코호트 리텐션, LTV
5. 채널·캠페인 효율 — 채널 ROI, 캠페인 비용 대비 매출, 베스트·워스트
6. 다차원 비교 분석 — 기간(이번·직전·전년 동기)·세그먼트(등급·RFM)·채널·캠페인 유형·신규vs기존·시간대 다각도 비교 (동종업체 외부 벤치마크 대신 내부 다차원)
7. 메시지·콘텐츠 분석 — 유형별(SMS/LMS/MMS) 성과, 반응 패턴, 최적 시점
8. 예측·기회 — 다음 기간 전망(실측), 놓친 타겟·잠재 매출
9. 우선순위 액션 플랜 — 순위 권고 + 예상 효과 + 여정·자동마케팅 1-click 연결
10. 부록 — 출처·기간·표본, 데이터 부족 항목 표기

## 4. 사용자 흐름
풀분석 버튼 → 설정 모달 → [실행] → 동의 모달(크레딧·시간) → [확인] → 진행도 모달 → 완료 → 보고서 화면 + PDF 다운로드

## 5. 모달 설계 (전부 다크 톤, native dialog 금지, ConfirmModal/useToast)

### 5-1. 설정 모달
- 기간: 7/14/30/90일 또는 직접 범위
- 보고서 목적 1택: 종합 / 매출성장 / 고객유지 / 채널효율 (목적별 AI 강조점 조정)
- 보고서 제목·회사명(회사 보고용)
- 마케팅 담당자 UX: 추가 입력 최소 — 목적만 1택, 나머지는 AI 자동

### 5-2. 동의 모달
- "이 기간 종합 분석에 300크레딧 + 약 N분 소요. 현재 잔액 X → 분석 후 X−300. 진행하시겠습니까?"
- 예상 시간 N = 최근 분석들의 실측 평균(데이터 없으면 기본값)
- 잔액 부족 시 차단 + 충전 안내

### 5-3. 진행도 모달
- 비동기 job — 실제 단계별 진행 반영: 데이터 수집 → 성과 진단 → 원인 분석 → 세그먼트 → 다차원 비교 → 채널 → 예측 → 액션 → PDF 생성
- 각 단계 상태·진행률, 프리미엄 시각 기본(디자인 룰 — violet 액센트, 단계 카드, 700ms 연출). 15만원 가치에 맞는 압도적 디자인 — 허접한 로딩 금지
- 완료 시 보고서 화면 전환

## 6. 생성 엔진
- 백엔드 비동기 job: 기간 실측 데이터 수집 → 섹션별 분석 → AI 종합 → 구조화 보고서 데이터 → PDF 렌더
- 분석 단계 구조(섹션 병렬/순차)는 구현 plan에서 확정
- AI 모델 = Operator 계열(기존 한줄로AI 흐름과 분리)
- 진행 상태 폴링(job 상태 endpoint)
- 실데이터 기반, 임의 상수 0, 데이터 부족 정직 표기

## 7. 크레딧 정책
- 300크레딧, job당 멱등 1회
- 차감 시점: 분석 시작(동의 확인) 시 차감 + 실패 시 환불(배치 차감-후-환불 패턴) — 확정
- 잔액 부족 시 시작 차단

## 8. PDF
- pdfkit(기존 의존성). 표지·목차·섹션·차트·부록의 정식 보고서 디자인
- 차트 서버 렌더

## 9. 데이터 소스 (구현 시 information_schema 선검증 의무 — db_column_verify)
- campaigns, 캠페인 결과(MySQL), cdp_events, 매출, 고객·세그먼트 등
- 신규 SELECT/JOIN 컬럼·테이블은 information_schema 덤프로 실재 확인 후 코드 작성

## 10. 확정 결정 (2026-06-08)
- 크레딧 차감: 분석 시작 시 차감 + 실패 환불 (멱등)
- 예상 소요시간: 최근 분석 실측 평균으로 "약 N분" 표시
- 보고서 목적: 4개 유지 (종합 / 매출성장 / 고객유지 / 채널효율)
- 동종 벤치마크: 제외 → 내부 다차원 비교 분석으로 대체 (§3-6)

## 11. 비범위 (YAGNI)
- 동종 벤치마크(별도 트랙으로 분리)
- 실시간 협업 편집, 보고서 다국어
