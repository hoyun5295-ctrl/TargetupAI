## 1. 검토 배경

인공지능 기본법상 인공지능사업자는 자사가 제공하는 인공지능 또는 이를 이용한 제품·서비스가 고영향 인공지능에 해당하는지를 **사전에 검토**하여야 한다. 본 문서는 그 검토 결과와 판단 근거를 기록한 것이다.

당사는 파운데이션 모델을 직접 개발하지 않으며, 외부 사업자가 제공하는 생성형 인공지능 API를 이용하여 이용자(고객사)에게 마케팅 자동화 서비스를 제공하는 **AI이용사업자**에 해당한다.

## 2. 당사 서비스의 인공지능 활용 범위

**판단 단위**: 고영향 해당 여부는 개별 기능이 아니라 **이용자에게 제공하는 제품·서비스 단위**로 판단한다. 따라서 아래는 한줄로 서비스가 제공하는 인공지능 활용 기능 전체를 대상으로 한다.

| 구분 | 기능 | 인공지능 활용 내용 | 산출물의 성격 |
|------|------|-------------------|--------------|
| 콘텐츠 | 문안 생성 | 마케팅 메시지 문구 초안 생성 | 고객사가 검토·수정·승인 후 발송 |
| 콘텐츠 | 이미지 스튜디오 | 상품 이미지 기반 마케팅 포스터 생성 | 고객사가 선택·저장 후 사용 |
| 콘텐츠 | 모바일 DM·이메일·인앱 편집기 | 섹션 구성·카피 작성 보조 | 고객사가 편집·발행 |
| 콘텐츠 | 이미지 판독 | 고객사가 업로드한 행사 이미지에서 상품·가격 정보 전사 | 고객사 콘텐츠 제작 보조 |
| 콘텐츠 | 브랜드 보이스 학습 | 고객사 과거 문안의 어조·표현 학습 | 문안 생성 시 참고 |
| 대상 | 타겟 추출 | 구매 이력·등급 등 고객사 보유 데이터 기반 발송 대상 산출 | DB 실쿼리 결과. 예측값을 대상 선정 조건으로 사용하지 않음 |
| 대상 | 예측 분석 | 이탈·구매 가능성 등 추정치 산출 | 추천·개인화·발송 시점 제안에만 사용(§4-3) |
| 운영 | 발송 시점 추천 | 반응 이력 기반 발송 시각 제안 | 고객사가 채택 여부 결정 |
| 운영 | 여정 자동화 | 발송 시나리오 설계 보조 | 고객사가 검토 후 활성화 |
| 운영 | 자동마케팅 | 사전 정의된 조건 충족 시 캠페인 실행 | 고객사가 사전 승인한 시나리오 범위 내에서만 동작 |
| 운영 | AI 운영 진단·추천 | 성과 데이터 기반 개선 제안 | 제안 단계. 실행은 고객사 결정 |
| 품질 | 스팸필터 테스트 | 발송 전 메시지의 스팸 차단 가능성 점검 | 고객사에 대한 사전 경고·재작성 제안 |

**공통 특성**: 모든 산출물은 광고·마케팅 커뮤니케이션 영역에 한정되며, 개인의 권리·의무 관계를 변동시키는 결정을 내리지 않는다. 최종 발송 여부는 항상 고객사(사람)의 확인과 실행에 의해 결정되며, 자동마케팅·여정 등 자동 실행 기능도 고객사가 사전에 설계·승인한 시나리오의 범위를 벗어나지 않는다.

**서비스 밖 영역**: 당사는 금융·의료·공공·교육·교통·에너지 등 고영향 영역의 업무 시스템에 인공지능을 공급하지 않으며, 이용자는 자사 상품·서비스를 마케팅하는 민간 기업이다.

## 3. 고영향 인공지능 영역별 해당 여부

법 제2조제4호가 정한 영역별로 검토한 결과는 다음과 같다.

| 고영향 영역 | 해당 여부 | 판단 근거 |
|------------|----------|----------|
| 에너지 공급 | 해당 없음 | 에너지 관련 기능 없음 |
| 먹는물 공급 | 해당 없음 | 관련 기능 없음 |
| 보건의료 제공·이용체계 | 해당 없음 | 의료 정보 처리·진단·판독 기능 없음 |
| 의료기기 | 해당 없음 | 의료기기에 탑재되지 않음 |
| 핵물질·원자력시설 관리 | 해당 없음 | 관련 기능 없음 |
| 생체인식 정보 분석·활용 | 해당 없음 | 지문·홍채·얼굴 등 생체인식 정보를 수집·처리하지 않음 |
| 채용·대출 심사 등 개인의 권리·의무에 중대한 영향을 미치는 판단·평가 | **해당 없음** | 아래 4항에서 별도 상술 |
| 교통수단·교통시설·교통체계 작동·운영 | 해당 없음 | 관련 기능 없음 |
| 공공서비스 자격 확인·결정, 비용 징수 등 국가기관 등의 의사결정 | 해당 없음 | 국가기관 의사결정에 사용되지 않음. 이용자는 민간 기업 |
| 학생 평가 | 해당 없음 | 교육 평가 기능 없음 |

## 4. 유일한 검토 쟁점 — "개인의 권리·의무에 중대한 영향을 미치는 판단·평가"

당사 서비스는 고객 데이터를 분석해 발송 대상을 선별하므로, 이 영역에 대한 정밀 검토가 필요하다. 검토 결과 해당하지 않는다고 판단하며 근거는 다음과 같다.

1. **결정의 대상이 권리·의무가 아니다.** 산출물은 "광고 메시지를 수신할 대상"의 선별이다. 법이 예시하는 채용·대출 심사와 달리, 선별 결과가 개인의 법적 지위·재산권·자격을 변동시키지 않는다. 선별되지 않은 개인에게 발생하는 효과는 광고 메시지를 받지 않는 것뿐이다.
2. **불이익 처분이 존재하지 않는다.** 서비스는 혜택·정보의 제공(광고 발송)만을 수행하며, 거절·박탈·제한에 해당하는 처분을 산출하지 않는다.
3. **예측값을 대상 선정 조건으로 사용하지 않는다.** 발송 대상은 고객사가 보유한 실제 데이터에 대한 데이터베이스 조회 결과로 산출한다. 이탈 확률·구매 확률 등 예측 모델의 출력은 추천·개인화·발송 시점 제안에만 사용하고, 발송 대상 여부를 결정하는 조건으로는 사용하지 않는다(사내 개발 원칙으로 명문화·운영 중).
4. **사람의 결정이 항상 개입한다.** 인공지능의 산출물은 제안 단계에 머물며 발송 실행은 고객사 담당자의 확인·승인을 거친다. 여정·자동마케팅과 같이 조건 충족 시 자동 실행되는 기능도, 실행 조건·대상·문안을 고객사가 사전에 설계하고 활성화한 범위 내에서만 동작하므로 인공지능이 독립적으로 개인에 관한 결정을 내리지 않는다.
5. **수신자의 통제권이 보장된다.** 수신동의 및 수신거부(080·링크) 절차가 상시 제공되어, 개인이 언제든 처리 대상에서 이탈할 수 있다.

## 5. 결론 및 이행 사항

당사가 제공하는 인공지능 기반 제품·서비스는 **고영향 인공지능에 해당하지 않는다.** 따라서 고영향 인공지능 사업자에게 부과되는 강화된 책무(위험관리방안 수립, 설명요구권 보장 등)의 직접 적용 대상이 아니다.

다만 다음 의무는 고영향 해당 여부와 무관하게 이행한다.

- **사전 고지**(법 제31조제1항): 생성형 인공지능 기반 운용 사실을 이용약관 및 서비스 화면에서 고지
- **생성물 표시**(법 제31조제2항): 인공지능 생성 결과물에 대한 표시. 서비스 화면 내 표시 및 외부 반출(다운로드·발송) 시 결과물 표시 체계 구축 — 별도 이행 계획으로 관리
- **딥페이크 기준 회피 조치**: 이미지 생성 기능이 실제 사람과 유사한 인물 이미지를 생성하지 않도록 통제하여, 일반 생성물 표시 기준을 적용받도록 관리

### 인접 법령 — 별도 관리 대상 (본 검토서의 결론과 무관하게 이행)

- **개인정보 보호법상 자동화된 결정에 대한 정보주체의 권리**: 완전히 자동화된 시스템으로 개인에 관한 결정을 하는 경우 거부·설명요구권이 발생한다. 당사 서비스는 §4에 기재한 바와 같이 개인의 권리·의무에 관한 결정을 산출하지 않으나, 향후 기능 변경 시 이 조항의 적용 여부를 별도로 검토한다.
- **개인정보 처리 지위**: 당사는 고객사(위탁자)의 개인정보를 처리하는 **수탁자** 지위이며, 위탁계약·안전조치·처리방침 관리는 별도 체계로 운영한다.
- **정보통신망법상 영리목적 광고성 정보 전송**: 수신동의·수신거부·야간 발송 제한 등은 발송 기능 자체의 준수 사항으로 상시 적용한다.

## 6. 재검토 트리거

다음 중 하나가 발생하면 본 검토서를 즉시 재작성한다.

- 신용·대출·보험 심사, 채용·인사 평가 등 개인의 권리·의무에 영향을 주는 판단 기능을 도입하는 경우
- 생체인식 정보를 수집·분석하는 기능을 도입하는 경우
- 예측 모델의 출력을 발송 대상 선정 조건으로 사용하도록 정책을 변경하는 경우
- 공공기관 의사결정 지원 용도로 서비스를 공급하는 경우
- 법령·시행령·과기정통부 가이드라인상 고영향 영역이 개정되는 경우
