## §2 처방

### A. 스튜디오 용도별 제작

| 번호 | 처방 |
|---|---|
| A1 | **용도 고르기**: 템플릿을 고르고 「제작」 → 창 「어디에 쓸 그림인가요?」 = 여러 개 고르기 넷(인앱 메시지 · 모바일 DM · 이메일 마케팅 · 자유 형태) · 처음엔 아무것도 안 고름(하나 이상 골라야 만들기) · 인앱 메시지를 고르면 바로 아래 「글 자리: 위 / 아래」(기본 위) · 아래 줄 = 「N개 × 2크레딧 = M크레딧」. 프리셋(한 곳 `image-studio.ts CHANNEL_PRESETS`) = `use-inapp`(1:1 · `inapp-poster`) · `use-dm`(3:4 · `dm`) · `use-email`(4:3 · `email`) · `poster`(자유 · 3:4 · 지금 그대로). 옛 키(`inapp-poster` · `dm-card` · `email-hero` · `free` · `mms`) = 옛 임시 · 자산 해석용 그대로(값 바꾸지 않음) |
| A2 | **고른 수만큼 만들기**: 「만들기」를 누르는 순간 용도마다 **칸(slot)** 을 만든다 = { 용도 · 시도 표(attemptToken) · 요청 본문(그때 입력을 얼린 사본 · 템플릿 · 문구 · 제품 · 장면 힌트 · 혜택 · 글 자리 · 프리셋) }. 화면이 칸마다 `/generate` 를 차례로 부른다(회사당 동시 1건 잠금 · 지금 과금 규칙 그대로 = 한 번 2크레딧 · 성공 뒤 차감). 실패 · 응답 유실 칸 = 그 칸의 「다시 만들기」가 **같은 표 + 같은 얼린 본문**을 그대로 보낸다(그 사이 입력을 바꾸거나 다른 칸이 성공해도 서버 시도 키가 같아 기억 결과 · 한 번만 걷힘 · Codex 설계 1R ①) · 칸은 성공 결과를 받은 뒤에만 표를 버린다 · 진행 글 「2 / 4 · 모바일 DM 만드는 중」 · 결과 카드마다 용도 표지 + 그 용도 채널 버튼 하나(자유 = 채널 셋) |
| A3 | **인앱용 그림 규칙**(프롬프트): 정사각 · 화면 꽉 찬 그림(테두리 · 상자 · 띠 0) · 고른 쪽(위 / 아래)을 장면과 같은 색감의 자연스러운 빈 공간으로 두고 그 자리에 글 · 상품 · 주제는 반대쪽 · **글 · 상품 · 주제 = 가로 · 세로 모두 가운데 80% 안 · 가장자리 10% = 배경만**(앱이 가운데 맞춤 cover 로 5:4 ~ 4:5 칸을 채워 잘라도 배경만 잘림 = 스타벅스 방식 · Codex 설계 1R ③). `textPosition` = 인앱 용도면 모든 템플릿에 보냄(지금 = 행사만). **표지 = 그림 파일 이름**(Codex 설계 2R ① · 장 칸 표지는 두지 않는다): 스튜디오가 인앱용(`use-inapp`)을 영구 저장할 때 파일 이름 = `<임시 id>.full.<확장자>` · **영구 이름 만들기 · 다시 찾기 · 되돌리기 = 계약 하나**(Codex 설계 3R ①): 이름 CT `studioPermanentName(id, ext, full)` 하나를 `moveTempToPermanent` · `writeStudioPermanent` 가 쓰고, `findPermanentByTempId` 는 두 이름(`<id>.<ext>` · `<id>.full.<ext>`)을 다 찾고, `restorePermanentToTemp` 는 실제로 옮긴 파일 이름(돌려받은 값)으로 되돌린다(라이브러리 등재 실패 되돌림 · 저장 응답 유실 다시 요청 = 지금처럼 동작) → 그림을 다른 것으로 바꾸면 주소가 바뀌어 표지도 저절로 빠진다(따로 지울 칸 0 · 복제 · 교체 · 라이브러리 · 몰 상품 = 그 그림 이름대로). 판정 한 곳 = 서버 `isFullBleedInAppImage(url)`(우리 그림 · 파일 이름 `.full.` · 화면 거울 같은 정규식) |
| A4 | **편집기 안 스튜디오** = 용도 고정(묻지 않음): DM 창 = `use-dm` · 인앱 창 = `use-inapp` + 글 자리(통짜 = 위 / 아래 고름 · 사진 위 글 장 = 글 없는 판 · 아래 비움) |
| A5 | **만드는 중 안내** = 가운데 흰 카드(그림자 · 둥근 모서리) 위 진한 글씨 「완성 포스터를 만드는 중 (2 / 4)」 + 「창을 닫지 마세요」 · 바탕 = 어둡게만(흐림 0) |

### B. 인앱 앱 채널 = 되는 것만

| 번호 | 처방 |

| B1 | **앱 채널 모양 = 어느 깔린 앱에서든 그대로 보이는 것만**(판정 한 곳 = 서버 CT `appShapeAllowed(template, design)` + 화면 거울 · 같은 표본 대조): 통짜 포스터(`baked_sheet`) · 사진 위 글(`overlay`) · 가운데 팝업 · 하단 시트. 뺌 = 통짜 카드 · 사진 위 글 카드(떠 있는 카드 = 깔린 앱이 못 그림) · 이벤트 카드 · 배너 시트(앱 연동 판 v3 이 아니면 안 그림 · 보장 불가) · 기능 띠 쿠폰 · 남은 시간(복사 · 시계 = 깔린 앱에서 동작 0). 웹(자사몰 SDK) = 지금 그대로 전부. 이미 뺀 모양으로 저장된 앱 메시지 = 동작 바꾸지 않음 · 편집기 모양 칸에 「이 모양은 앱에서 그대로 보이지 않아요」 + [모양 바꾸기] · 입구 갤러리 · 모양 메뉴 · 띠 칸 모두 같은 판정 한 곳(`layoutsFor` · `stripAllowedFor(k, channel)`). **우회 입구 전부 같은 판정**(Codex 설계 1R ②): ① 가운데 팝업 「장 추가」(`InAppMessagesPage.tsx:2311` = 지금 이벤트 카드로 바꿈) → 앱이면 사진 위 글로 ② 채널 전환 · 새 메시지(예시 · AI 생성 · 플래너 · 복제 · 스튜디오 초안) = 앱으로 들어올 때 `appSafeDesign` 이 뺀 모양을 가장 가까운 모양으로(통짜 카드 → 통짜 · 사진 위 글 카드 · 이벤트 카드 · 배너 → 사진 위 글 · 띠 지움) ③ 서버 = 앱 채널 생성 · 수정에서 **뺀 모양으로 바뀌는 것만** 400(이미 그 모양인 저장 행을 그대로 저장 = 허용 · 보존 예외는 저장된 행에만) ④ **A/B 변형 만들기**(`createVariant` · `cdp.ts:1952` · 부모 채널 · 모양을 물려받아 새 행) = **새 자식의 최종 값**(요청 template · 물려받은 design · channel 을 합친 것)에 `appShapeAllowed` · 앱이면 금지 모양 400(부모가 허용이어도 요청 template 이 금지면 400 · 보존 예외는 새 자식에 물려주지 않음 · Codex 설계 2R ② · 3R ②) |
