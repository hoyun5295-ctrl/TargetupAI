## 1. 정체성

"AI 이미지 생성 도구"가 아니라 **브랜드 에셋 라이브러리 + 전 채널 1클릭 소재 공급**. 만들고 끝(캔바·범용 챗봇)이 아니라 만들고 → 라이브러리 축적 → 인앱 포스터형·DM·이메일·MMS 규격으로 바로 꽂힌다. 마케팅 캘린더 메뉴 자리를 대체(3행 중앙 카드 교체), NEW 뱃지 4~6주.

## 4. API 연동 스펙 (Interactions API — 문서 실측)

- 호출 형태(문서 원형): `client.interactions.create(model, input, response_format: { type: "image", aspect_ratio, image_size }, generation_config: { thinking_level })` → 응답 `output_image.data`(base64) + `output_text`. Node는 공식 genai SDK 또는 REST 동형 호출(구현 시 REST 실측 후 확정 — 응답 스키마 추측 금지 룰).
- 해상도·비율: image_size 512px/1K/2K/4K × aspect_ratio(1:1·16:9·9:16·3:4 등 문서 표 전체 지원). 채널 프리셋 매핑:

| 프리셋 | aspect_ratio | image_size | 소비처 |
|---|---|---|---|
| 인앱 포스터형 | 3:4 | 2K | full_image 카드(세로 포스터) |
| DM 카드 | 1:1 | 1K~2K | 모바일 DM 미디어 |
| 이메일 히어로 | 16:9 | 2K | 이메일 상단 |
| MMS | 3:4 | 1K | 용량 제한 축(저장 시 압축) |
| 자유 | 사용자 선택 | 1K~2K | 라이브러리 범용 |

- 편집: 입력 이미지 동봉(라이브러리/업로드/연동 상품 이미지) + 지시 프롬프트 — 상품 배너 1클릭의 합성 축.
- Batch API: 24h 처리·고한도 — **시즌 선제 생성(P5+)의 원가 절감 경로**로 예약(v1은 동기 호출만).
- 사고 토큰이 기본 청구됨 → `thinking_level`은 낮게 고정 시작(품질 실측 후 조정).

## 5. 아키텍처

### 5-1. Backend (신규 라우트 /api/image-studio + CT utils/image-studio.ts)
1. `POST /generate` — {prompt, preset, aspect_ratio?, image_size?, ref_asset_id?} → 무료 쿼터/크레딧 확인 → Gemini 호출(2장 병렬) → **temp 저장소**에 파일 기록(`uploads/studio-temp/{companyId}/`) → {tempId, url}×2 응답. 성공 시에만 차감.
2. `POST /save` — tempId → 실 저장소 이동 + cdp_assets 등재(kind='generated', prompt 저장, origin='studio'). **temp는 DB 미등재·7일 스윕**(크론 1일 1회 mtime 기준 삭제 — "임시 생성물 7일 자동 삭제(화면 명시)" 확정의 구현체. DB 변경 0).
3. `POST /remove-bg` — 자가 호스팅 rembg 실행(무료) → temp 산출.
4. `POST /edit` — 입력 이미지 + 지시 → 1크레딧(생성과 동일 흐름).
5. 크레딧: 기존 크레딧 CT 재사용(차감·잔액·사전 모달 — 구현 시 소비처 grep으로 함수 확정). 무료 쿼터 = 월별 카운트 테이블 불필요 — cdp_assets/차감 이력으로 산출 가능한지 구현 시 확정, 안 되면 경량 카운터 1컬럼 ALTER(그때 information_schema 절차).
6. env: `GEMINI_API_KEY`(Harold 등록), `GEMINI_IMAGE_MODEL`(기본 gemini-3-pro-image). 키 미설정 = 기능 카드에 "준비 중" 정직 표기(500 금지).

### 5-2. Frontend (신규 페이지 /image-studio — Journey 동급 디자인)
- 상단 sticky 헤더 + 그라데이션 아이콘 + NEW 뱃지.
- **자연어 프롬프트 카드**(fuchsia/purple 그라데이션 + Enter) + 채널 프리셋 칩 5종 + 참조 이미지(업로드/라이브러리/연동 상품 픽커 재사용).
- 결과: 후보 2장 그리드 → 각 장에 [라이브러리에 저장] [4K로(2크레딧)] [AI 편집(1크레딧)] [누끼(무료)] — 저장 전 산출물엔 "7일 후 자동 삭제" 명시.
- 우측: 내 라이브러리 최근 소재(AssetLibraryPickerModal 재사용) + 사용량(무료 쿼터 잔여·용량 게이지).
- 시즌 선제 제안 카드: 다가오는 시즌(기존 시즌 컨텍스트 자산 재사용) 소재 프롬프트 제안 — 표시 무료, 생성 클릭 시 1크레딧.
- 메뉴: SUB_MODULE_CARDS 3행 중앙 카드 교체(마케팅 캘린더 → 이미지 스튜디오, path /image-studio). MarketingCalendarPage 라우트는 유지(내부 진입 링크만 제거 — 비파괴, 추후 정리).

### 5-3. 가드레일 (영구 룰 상속)
- **혜택 문구 픽셀 금지**: 시스템 프롬프트에 "이미지 안에 텍스트·숫자·할인율 넣지 않기" 고정 지시 + UI 안내 "문구는 각 채널 편집기의 텍스트로 얹으세요"(인앱 포스터 오버레이·DM 텍스트와 접속). AI 임의 혜택 룰의 이미지판.
- 모델명 UI 노출 금지 — "AI 이미지 생성"만. 세이프티 거부 시 정직 안내 + 미차감.
- 지표·미리보기 목업 금지. 생성 실패 로그 PM2.
