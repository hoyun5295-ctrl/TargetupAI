## §1 정체성 — 무엇을 만드는가

**마케터는 질문에 답하고, 마스터프롬프트는 시스템이 조립한다.**
마스터프롬프트의 실체는 자연어 한 덩어리가 아니라 세 갈래다:

| 갈래 | 담는 것 | 생성기 결합 지점 |
|---|---|---|
| **사실 원문(eventText)** | 사용자가 **직접 타이핑·확인한** 사실만 — 행사명·기간·혜택(verbatim)·상품명·유의사항 | `oneShotGenerate({eventText})` → EventBrief → 출구 가드 |
| **결정 파라미터(decisions)** | 후킹 방식·긴급성·증거 블록·큐레이션 수·이미지 소스·매장 노출 — **AI 산출을 덮는 결정값** | 신설 `structure` 1급 파라미터(§4-2) — 섹션 체인을 결정적으로 고정 |
| **톤(주입)** | 브랜드 보이스·성과 문안 few-shot·업종 공식 | `composeCopyBrain` 기존 축 그대로 — **인터뷰는 묻지 않는다** |

1클릭 UX 원칙과의 관계: 전 문항에 프리필·파생 기본값이 있어 **[이대로 만들기] 한 번으로 완주 가능**하다.
질문은 "원하는 사람만 더 정확하게"의 경로다. 기존 자연어·빠른 시작 진입은 손대지 않는다.

## §3 화면 설계 (프론트·디자이너 수렴)

- **셸**: 아코디언 스텝. `CdpIntegrationStepper`는 props·완료판정 전제가 CDP 전용이라 **재사용이 아니라 사본**이 맞다(회의론자 판정) — 시각 규약(펼친 단계 하나·done/active 뱃지·`aria-current`)만 가져오고 라벨·안내 문구는 사용자 노출 검수를 다시 통과시킨다. **미래 문항은 잠그지 않는다** — 접힌 채 답 요약 한 줄 노출(프리필 6개가 "이미 채워짐"으로 읽히게).
- **진행 표시**: 도트·"3/7" 금지. **"확인할 것 N개"**(실입력 필요 축만) + 비율 바(`JourneyDataScopeNote` 2칩 형식).
- **프리필 표시**: 실값 + 출처 칩("연동몰에서 가져왔어요") + [수정]. 못 채운 것은 amber 문장으로 실토(항목별 정직 — `AiPromptModal`의 brief/missing 2블록 형식). 수정 후 재계산 금지.
- **[이대로 만들기] 상시** + 하단 스텝별 [지금 생성] 버튼 금지(스텝마다 차감 — 백엔드 판정). 생성은 최종 1회.
- **결과 화면**: 실제 미리보기(합성 값 금지) + 반영 검산 칩(coverage) + **안 채운 결정축 인라인 채움**(칩을 누르면 그 자리에서 라벨+desc 2줄 선택지가 펼쳐진다 — 화면 전환 없음) + Source caption("귀사 브랜드 톤 + 최근 발송 성과 기준") + 1-click 3카드([발송 준비]/[문안만 다듬기]/[질문 2개만 다시]).
- **감성**: 상단 헤더에 "받아적은 답 요약"(상담 노트) · eyebrow 타이포 · 흰 버튼은 최종 확정 1곳.
- **금지·의무**: 백드롭 클릭 닫힘 금지(모달이면 닫힘 차단 축) · z 티어(내부 픽커·크레딧 모달 z-[2000]와 충돌하지 않게 셸은 아래 티어) · 조기 return 뒤 훅 금지 · 모바일 반응형 · 모델명 0 · native dialog 0.
- **중도 이탈**: DB 초안 + 재개 바. 저장 축은 §6-1에서 확정(회의론자 E — `event_campaign_drafts` 재사용 시 기존 재개 바가 인터뷰 행을 3채널 모달로 열어버리는 결함 → 재사용하려면 조회 제외 조건을 같은 커밋에, 아니면 별도 축).

### 4-2. 생성기 결합 — §0 판정 A·B를 닫는 유일 경로

`oneShotGenerate`에 `structure?: { sectionTypes: SectionType[]; scenarioKey?: string; decisions: InterviewDecisions }`를 신설한다.
- `structure`가 오면: `parsePrompt` 미호출(spec은 결정적 기본값 조립) · `designSectionLayout` 미호출 · 섹션 체인 = `normalizeSectionChain(structure.sectionTypes)`.
- 계약 테스트의 단정 대상은 **정규화 이후** 최종 체인이다(§0 판정 D).
- 프리필 상품은 eventText가 아니라 `structure.decisions.products`로 — 몰 매칭이 이미 검증한 실데이터라 원문 자격이 필요 없다(§0-6).
- eventText에는 **사용자가 타이핑·명시 확인한 값만** 직렬화한다(라벨 집합은 EventBrief 필드와 1:1 — 매장·유의사항·링크 포함).

### 4-3. 파생 기본값 (1클릭 완주의 실체)

긴급성 = `period_end` 실존 시에만 / 큐레이션 = 선택 상품 수 / 매장 = brandKit 주소 실존 / 이미지 = 몰 정확 매칭 성공 / 증거 = **기본 OFF**(파생 불가 — 안 물었으면 안 넣는다).
전부 축소 방향 파생이라 "예측 타겟 선정 금지"·"0건 자동완화 금지"와 부딪히지 않는다(회의론자 판정 2).

### 4-4. 요금 (§0-7)

- 차감 = 채널 생성 키(`one-step-gen:{sessionId}:dm` — dm-ai-generate 5) + **오토설계 대행 델타 `one-step-interview` = 50**(멱등키 `one-step:{sessionId}` · 세션당 1회 · ★2026-08-13 Harold 확정).
  - **50의 근거는 임의 숫자가 아니다** — `email-campaign-complete: 50`(설계·완성 대행)과 같은 부류·같은 값이다. 고객 설명도 "완성 대행급"으로 선다.
  - 총액 = 생성 5 + 델타 50 = **55**(발행 100은 발행 시점 별도) → 직접 생성 세트 105 대비 **약 1.5배**. 2배(정액 210)는 §0-7로 기각됐다.
  - **원가는 오르지 않는다.** 인터뷰·프리필·견적은 AI 호출 0이고, 생성 단계에서도 결정 파라미터가 `parsePrompt`·`designSectionLayout` 두 호출을 대체해 **기존 경로보다 호출이 준다**(§4-2). 델타의 근거는 원가가 아니라 **대행 가치**다(플래너 요금 철학의 대행 축 — 제작물=원가 연동 / 대행=가치 연동).
  - **재생성은 델타를 다시 걷지 않는다** — 세션 멱등 1회라 재생성 시 생성비 5만 나간다("대행비를 냈는데 또 낸다"가 원천적으로 없다).
  - **인상은 계측 뒤에** — §4-5 대조군으로 "인터뷰 결과물이 측정 가능하게 낫다"가 나온 뒤 100 검토(그 전에 올리면 증거 없이 가격이 앞선다).
- 발행은 기존 `dm-publish:{dmId}` 그대로(이중과금 0 — 플래너 §3-10 규약).
- **견적 = 서버 순수 함수 하나**가 표시·실차감을 같이 소유(정적 상수 맵으로는 "표시 ≠ 차감" 재현 — 회의론자 판정 3). 20크레딧+ 모달은 그 견적을 표시. 재생성 시 채널 생성비 재차감을 화면에 사전 고지.
- 인터뷰·프리필·견적은 AI 호출 0 = 무과금.

### 4-5. 계측 (프리미엄의 사후 증명)

- coverage 적재를 **인터뷰 세션과 기존 one-shot 경로 양쪽에**(이미 계산돼 응답에 실리는 값의 저장뿐) — 대조군 없이는 델타를 방어할 수 없다(회의론자 F).
- 결정축 반영은 coverage가 원리상 못 재므로 **정규화 후 최종 sectionTypes를 세션에 기록**해 비교 축으로 쓴다.
- 문항 단위 이탈 계측(어느 키에서 닫았나).

## §6 확정 원장 (회의 뒤 닫은 것)

### 6-1. 초안 저장 축 = **신규 테이블 `one_step_sessions`** (DDL 1건 · ★2026-08-13 확정)

`event_campaign_drafts` 재사용을 접은 이유 셋:
1. **소비처 오염** — 그 표를 읽는 `EventCampaignResumeBar`가 두 화면에 붙어 있고, 인터뷰 행은 `channels` payload가 비어 **라벨 없는 칩**으로 떠서 누르면 3채널 모달이 열린다(인터뷰로 못 돌아간다). `source_kind` 필터를 넣어 막을 수는 있으나, 접목 대상이 5곳으로 늘면 그 필터를 **모든 소비처에 유지**해야 한다.
2. **축이 섞인다** — 그 표의 소유는 "행사 캠페인 3채널 세트"(파일 헤더 명시)다. 인터뷰 세션은 답변·프리필 스냅샷·정규화 후 최종 체인·커버리지·차감 멱등키를 갖는 **다른 수명의 개체**다.
3. **그 표는 SCHEMA.md 미등재**(grep 0건)라 재사용 쪽도 어차피 `information_schema` 선행이 필요하다 — 재사용의 "DDL을 아낀다"는 이점이 크지 않다.

**DDL (★2026-08-13 확정 · 배포 직후 실행 — 그 전에는 코드가 503 `DB_MIGRATION_PENDING`으로 답한다)**

```sql
CREATE TABLE IF NOT EXISTS one_step_sessions (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  company_id uuid NOT NULL REFERENCES companies(id) ON DELETE CASCADE,
  created_by uuid REFERENCES users(id) ON DELETE SET NULL,
  channel varchar(20) NOT NULL DEFAULT 'dm',
  answers jsonb NOT NULL DEFAULT '{}'::jsonb,
  prefill jsonb NOT NULL DEFAULT '{}'::jsonb,
  decisions jsonb NOT NULL DEFAULT '{}'::jsonb,
  section_types jsonb NOT NULL DEFAULT '[]'::jsonb,
  coverage jsonb,
  result_ref uuid,
  attempt integer NOT NULL DEFAULT 0,
  interview_paid_at timestamptz,
  status varchar(20) NOT NULL DEFAULT 'draft',
  created_at timestamptz NOT NULL DEFAULT NOW(),
  updated_at timestamptz NOT NULL DEFAULT NOW()
);
CREATE INDEX IF NOT EXISTS idx_one_step_sessions_company ON one_step_sessions(company_id, created_at DESC);
```

- `attempt` = 생성 회차(생성비 멱등키에 들어간다) · `interview_paid_at` = 대행 델타를 걷은 표식(**재생성이 델타를 다시 걷지 않는 근거**).
- `section_types`는 **정규화 이후 최종 체인**을 남긴다 — 결정축 반영은 커버리지로 못 재므로 이것이 계측 축이다(§4-5).
⛔ 전 엔드포인트 owner-scope · `handleDbMigrationError` 503 분기 의무 · DDL은 **배포 직후** 실행.
**★2026-08-13 Phase 0 실측 완료** — `one_step_sessions`는 존재하지 않는다(이름 확보 · CREATE 그대로 진행). `event_campaign_drafts`는 10컬럼으로 실존하며 **SCHEMA.md에 등재 완료**(별건 ⑤ 해소).

### 6-2. 오토설계 대행 델타 = **50크레딧** (★2026-08-13 Harold 확정)

### 6-3. 증거 자산 검증 = **형식만 검증하고 도달성은 확인하지 않는다** (★2026-08-13 확정)

- **리뷰 = 사용자 입력 텍스트만 그대로 `reviews` props에 싣는다. AI 생성 절대 금지** — 없는 후기를 지어내는 것은 "AI 임의 혜택 금지"와 같은 부류이고 표시광고 문제로 직결된다. 입력이 없으면 그 섹션을 넣지 않는다.
- **영상·인스타 = URL 형식 검증만**(https 강제 + 호스트 화이트리스트). 외부 도달성 확인은 하지 않는다 — 호출당 원가·지연·실패 축이 늘고, 외부 응답 때문에 생성이 막히면 안 된다(og 이미지 조회가 이미 "실패=빈 값 유지, 생성 차단 X"로 정한 축).
- **검증 실패 = 그 증거 섹션만 제외 + 사유 표시.** 전체 생성 차단 금지(0건 자동완화 금지의 반대 방향 — 못 확인한 것을 넣지 않되 나머지는 살린다).
