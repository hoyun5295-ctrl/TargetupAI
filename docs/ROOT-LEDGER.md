## 왜 되풀이됐나 (2026-10-24 플래너 9건을 생긴 때로 가른 결과)

1. **새 규칙을 그 규칙이 생긴 기능에서만 고쳤다** — 1020 출처 0 · 1024 발송 직전 차감 · 지문에 번호 · 한 줄 + 질문 · 1019 이미지 스튜디오 서버 요금제 문 · 1018 검사 3분할이 다른 기능에 퍼지지 않았다.
2. **검토가 바뀐 줄만 본다** — Codex 증분 · 요청받은 기능만 구조체크라, 손대지 않은 옛 경로는 검토를 한 번도 받지 않는다.
3. **막은 것을 지키는 기계 장치가 없었다** — 기능마다 손으로 다시 막았다. 손으로 등재한 표는 등재한 것만 지킨다(LESSONS_BACKEND 1014).

그래서 시험은 **소스에서 기계로 대상을 뽑는다**(주소 · 호출 · 화면 파일). 표에 적은 예외만 통과하고, 새 주소 · 새 호출은 분류 없이 들어오면 실패한다.

## 점검표 (기계로 못 잡는 것 · 구조체크 · Codex 요청문에 의무)

- R1 같은 사실 두 벌 — 이번에 만든 값을 다른 곳이 따로 계산하는가(화면 · 검사 · 알림 · 발송 · 정산).

- R8 상한 없는 재시도 — 실패가 다음 주기에 같은 비용으로 다시 도는가 · 실패 행이 앞자리를 차지하는가.
