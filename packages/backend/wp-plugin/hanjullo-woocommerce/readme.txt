한줄로 AI 마케팅 연동 플러그인.

== 하는 일 ==

1. 방문·장바구니 수집 스크립트를 모든 페이지 head 에 자동으로 넣습니다(한줄로 SDK 공개키 입력 시).
2. 로그인 회원을 자동으로 식별합니다. 한줄로 연동 화면의 이 몰 줄에서 받은 플러그인 키를 넣어 두면, 이 서버가 페이지를 붙잡지 않고 한줄로에서 회원 토큰을 받아 둡니다 — 한줄로는 토큰이 있는 식별만, 몰 서버가 보낸 회원 정보와 같은 고객에 잇습니다(키는 이 몰 회원 토큰만 받을 수 있고 페이지에 실리지 않습니다 · 이메일 · 휴대폰 · 이름은 페이지에 싣지 않습니다).
3. 마케팅 수신동의 값(기본 mssms_agreement_label · email_agreement_label)을 우커머스 REST 회원·주문 응답에 함께 실어 한줄로가 광고 발송 대상을 정확히 가리게 합니다.

주문·회원 동기화 자체는 이 플러그인이 아니라 한줄로 관리 화면의 "우커머스 연결(관리자 승인)"에서 시작합니다.
승인하면 우커머스가 REST API 키를 한줄로에 전달하고, 한줄로가 웹훅 4개를 자동으로 만듭니다.

== 설치 ==

1. 워드프레스 관리자 → 플러그인 → 새로 추가 → 플러그인 업로드에서 zip 을 올리고 활성화합니다.
2. WooCommerce → 한줄로 에서 SDK 공개키를 넣습니다(선택).
3. 한줄로 관리 → 자사몰 연동 → 우커머스 → 관리자 승인으로 연결.

== 변경 이력 ==

= 1.0.3 =
* 로그인 회원 식별 키를 회사 CDP 비밀키에서 이 몰 전용 플러그인 키로 바꿨습니다(워드프레스 한 곳이 털려도 회원 · 주문 쓰기와 다른 몰 회원 토큰은 안 됩니다).
* 회원 토큰을 페이지 응답 뒤에 받아 두어 로그인 회원 페이지가 늦어지지 않습니다(처음 한 페이지는 익명 · 다음 페이지부터 식별).
* 도메인을 옮긴 몰도 회원 번호를 한줄로가 이 몰의 고정 식별자로 만들어 같은 고객에 잇습니다.
* 페이지에 이메일 · 휴대폰 · 이름을 싣지 않습니다.

= 1.0.2 =
* 로그인 회원 식별에 회원 토큰을 싣습니다(설정 = 한줄로 CDP 비밀키 · 이 서버에만 저장).
* 회원 식별자를 '몰 주소:회원 번호'로 보냅니다(몰이 여럿인 회사에서 같은 번호 회원이 합쳐지지 않게).
