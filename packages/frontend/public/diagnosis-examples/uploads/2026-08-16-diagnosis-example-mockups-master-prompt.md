# [마스터 프롬프트] 분야별 마케팅 예시 목업 제작 — 이메일 · 모바일DM · 인앱메시지

> 이 문서 전체를 디자인 담당 Claude 세션에 그대로 붙여넣어 지시한다.
> 용도: 한줄로 「AI 마케팅 진단」 결과 리포트·영업 제안서에 넣을 **분야별 예시 실물**.
> 이미지 스튜디오는 기존 카탈로그를 재사용하므로 제외 — 여기서 만드는 것은 카탈로그가 없는 3채널이다.
> 2026-08-16 작성. 카테고리·브랜드명·시나리오 표는 Harold가 수정할 수 있다 — 표가 바뀌면 산출물도 그 표를 따른다.

---

너는 마케팅 크리에이티브 디자이너다. 아래 규격대로 **분야(카테고리)별 마케팅 예시 목업 HTML**을 만든다. 이 목업은 잠재 고객사가 "우리 분야에서 이런 걸 만들 수 있구나"를 실물로 확인하는 자료다 — 데모 티가 나면 실패고, **실제 브랜드가 오늘 발송한 것처럼** 보여야 성공이다.

## 1. 산출물

카테고리 8개 × 채널 3종 = **24개 HTML 파일**. 파일 하나 = 예시 하나 = 완결된 화면 하나.

파일명 규칙: `<카테고리코드>-<채널코드>.html`
채널코드 = `email`(이메일 마케팅) / `dm`(모바일DM) / `inapp`(인앱메시지)
예: `fashion-email.html`, `beauty-dm.html`, `fnb-inapp.html`

한 번의 지시에 한 카테고리(3파일)씩 만들고, 완성 목록을 보고한 뒤 다음 카테고리로 넘어간다. 24개를 한 번에 쏟아내지 않는다 — 품질이 뒤로 갈수록 떨어진다.

## 2. 카테고리 표 (수정 가능 — 이 표가 진실)

| 코드 | 분야 | 가상 브랜드(제안 — 겹침 의심 시 변형) | 시나리오 제안 |
|---|---|---|---|
| fashion | 의류/패션 | 어반셀 (URBANCELLE) | 가을 신상 런칭 + 재입고 알림 |
| beauty | 뷰티/화장품 | 톤메이트 (TONEMATE) | 신제품 앰플 출시 + 회원 등급 혜택 |
| fnb | 식음료/카페 | 브루어리715 | 시즌 신메뉴 + 오전 방문 쿠폰 |
| ecommerce | 쇼핑몰/이커머스 | 데일리박스 | 장바구니 리마인드 + 무료배송 임박 |
| medical | 병원/의료 | 라온재활의학과 | 예약 리마인드 + 건강 정보 안내 |
| education | 학원/교육 | 스텝업클래스 | 신규 강좌 개강 + 조기등록 안내 |
| travel | 여행/레저 | 트립로그 | 연휴 특가 + 예약 마감 임박 |
| fitness | 피트니스/뷰티케어 | 무브짐 (MOVEGYM) | 재등록 시즌 + PT 체험 안내 |

- 브랜드는 **전부 가상**이다. 실존 브랜드의 상호·로고·슬로건·트레이드 드레스를 모방하지 않는다. 브랜드명이 실존 상표와 겹치는 것 같으면 네가 변형해서 짓고 보고한다.
- 시나리오는 그 분야 마케터가 "우리도 이거 보내는데"라고 느낄 전형이어야 한다. 제안 시나리오가 어색하면 더 전형적인 것으로 바꿔도 된다 — 단 바꿨다고 보고한다.

## 3. 하드 룰 — 하나라도 어기면 그 파일은 폐기

1. **자기완결 HTML 1파일.** 외부 요청 0 — CDN·웹폰트·외부 이미지·외부 CSS/JS 금지. 시각 요소는 인라인 CSS와 인라인 SVG로만 그린다. `<img src="http...">` 금지. 시스템 폰트 스택 사용(`-apple-system, "Malgun Gothic", sans-serif` 계열).
2. **사진이 필요한 자리는 SVG 일러스트나 CSS 그라데이션 구성으로 대체**하되, "이미지 없음" 느낌이 아니라 의도된 아트 디렉션으로 보이게. 제품 실루엣·패턴·색면 구성 적극 활용.
3. **AI 벤더·모델명 0** — Claude, GPT, Opus, Sonnet, Anthropic, OpenAI 등 단어가 주석 포함 어디에도 없어야 한다.
4. **연락처·링크는 전부 도달 불가 더미** — 전화 `02-000-0000`, 링크 `href="#"`, 이메일 `hello@example.com` 형태만. 실존 도메인·실번호 대역 금지.
5. **할인·혜택 수치는 시나리오 안에서 자연스러운 수준**(10~30% 구간, 과장 금지). "업계 1위", "효과 보장" 같은 검증 불가 문구 금지. 의료(medical)는 과장·효능 표현 자체를 피하고 안내·리마인드 톤으로.
6. **한국 광고 표기 관행 반영** — 이메일: 푸터에 수신거부 링크·발신자 정보(더미 주소) 포함. 모바일DM: 하단에 `무료수신거부 080-000-0000` 표기. 이것이 들어가야 실물처럼 보인다.
7. 한국어 카피. 맞춤법·띄어쓰기 검수. 어색한 번역투 금지.

## 4. 채널별 규격

### 4-1. 이메일 마케팅 (`*-email.html`)
- 본문 폭 600px 고정, 중앙 정렬, 바깥 배경은 옅은 회색(`#f4f5f7`).
- 구조: 브랜드 헤더(로고는 텍스트+SVG 마크) → 히어로(핵심 메시지 1문장) → 본문 섹션 1~2개(제품/혜택) → CTA 버튼 1개 → 푸터(발신자 정보·수신거부).
- 이메일 클라이언트 현실 반영: 레이아웃은 단순 세로 흐름, 버튼은 큼직하게.

### 4-2. 모바일DM (`*-dm.html`)
- 스마트폰 프레임(375×812) 안의 **모바일 랜딩 페이지**로 그린다 — 문자로 받은 링크를 열었을 때의 화면. 프레임 밖 배경은 무채색.
- 구조: 풀블리드 히어로 → 핵심 혜택 블록 → CTA 버튼(화면 하단 고정) → `무료수신거부 080-000-0000` 표기.
- 스크롤 없이 한 화면에 핵심이 다 보이게. 엄지로 누르는 화면이므로 터치 타깃 크게.

### 4-3. 인앱메시지 (`*-inapp.html`)
- 스마트폰 프레임(375×812) 안에 **그 브랜드의 앱 화면(흐림 처리된 배경)** 위로 인앱 카드가 떠 있는 형태. 배경 앱 화면도 네가 간단히 구성한다(상품 그리드 등 흐릿하게).
- 인앱 카드: 이미지 영역(SVG) + 카피 2줄 이내 + 버튼 1~2개(주 버튼 1 + 닫기). 카테고리마다 형태를 하나씩 달리해도 좋다(전면형/카드형/하단 배너형) — 3형태가 골고루 나오게.

## 5. 품질 기준

- 각 브랜드는 **자기만의 색·타이포 성격**을 가진다. 8개 브랜드가 같은 템플릿의 색만 바꾼 것처럼 보이면 실패다. 분야의 관습을 따르되(뷰티=정제된 여백, F&B=식욕 자극 난색, 의료=신뢰 한색) 그 안에서 브랜드 개성을 만든다.
- 카피가 절반이다. 헤드라인은 혜택이 아니라 **고객 상황**으로 연다("장마철 프리즈 없는 컬" > "신제품 출시"). 본문은 짧게, CTA는 동사로.
- 같은 카테고리의 3채널(email·dm·inapp)은 **같은 브랜드의 같은 캠페인**이어야 한다 — 한 브랜드가 한 캠페인을 3채널로 전개한 세트로 보이게. 이게 "채널을 조합해 쓰는 모습"을 보여주는 핵심이다.

## 6. 파일마다 자가 검증 후 제출

- [ ] 외부 요청 0 (파일 열어 네트워크 요청 없는지)
- [ ] 실존 브랜드·상호·로고 모방 없음
- [ ] 더미 연락처·`#` 링크만
- [ ] AI 벤더·모델명 0 (주석 포함)
- [ ] 수신거부/발신자 표기 (채널 규격대로)
- [ ] 맞춤법
- [ ] 3채널이 같은 브랜드·같은 캠페인 세트

산출 파일의 저장 위치는 지시자가 알려준다. 완성 시 카테고리별로 `코드-채널 3파일 + 바꾼 것(브랜드명·시나리오 변형 여부)`을 한 줄로 보고한다.
