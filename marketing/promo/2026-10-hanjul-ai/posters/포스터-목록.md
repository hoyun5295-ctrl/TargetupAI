# 홍보 영상용 포스터 · 만든 방법

서버 접속이 안 되는 기간(2026-10-23)이라 이미지 스튜디오 화면 대신 같은 방법으로 직접 만들었다.

- 프롬프트 = 이미지 스튜디오 실제 함수 `buildPosterPrompt` · `buildEditInstruction`(`packages/backend/src/utils/image-studio.ts`)에 템플릿 원장(`image-studio-templates.ts`)과 아래 문구를 넣어 조립한 그대로.
- 생성 = 같은 계열 이미지 모델(3:4 · 2K). 제품 포스터는 스튜디오 흐름 그대로 「원본 사진 → 배경 지움 → 누끼를 첨부해 생성」.
- 원본(2K PNG) = `raw/` · 영상용 = 이 폴더(`resize.py` 로 줄임).
- 브랜드는 영상용 가상 이름: 결온(뷰티) · 오후담(카페) · 소요웨어(의류).
